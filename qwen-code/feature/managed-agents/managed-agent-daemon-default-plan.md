# Managed daemon 默认实现：首阶段实施计划

本计划落实用户最新范围调整。目标是在保留当前 4170 预览和用户数据的前提下，将适用的新 daemon 会话切到 Managed 默认实现，继续使用现有 Agent 能力。MCP、Hooks、Channels 的 Managed 接入与迁移延期；已有能力保留原执行路径。此处列的是待完成任务，不能用已完成的内核或独立 Managed 页面验收代替默认入口验收。

| 顺序 | 工作                                                                                                    | 完成证据                                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 1    | 完成媒体 M2：PDF 原生进程取消、Gateway 转写、共享轮次预算及取消排空；随后实现 M3 的客户端展示和产物路径 | 原生 PDF 真实取消/退出和临时目录清理；worker 零模型请求；转写及失败回退一致；支持客户端实际展示                      |
| 2    | 补齐内置工具、工作区上下文和有效配置、后台进程、恢复及结果可交付性                                      | 从普通 Agent 核对的能力清单逐项有源码和行为证据，执行与关闭不依赖另一套本地工具                                      |
| 3    | 明确并实现首次创建时的执行所有者与兼容选择                                                              | 根据实际配置和入口选择；MCP/Hooks 依赖会话和 Channels 保留旧路径；既有会话按持久化所有者恢复，不在失败后换引擎       |
| 4    | 接通 Web Shell、SDK、手动和自动定时任务核心链路，兼容旧会话                                             | 普通 create/prompt/events/transcript/cancel 及队列、权限、重连、恢复、最终交付；两类定时任务均实际单次执行           |
| 5    | 切换 primary/secondary/replacement 创建策略并完成首阶段验收                                             | 隔离的普通 daemon 多工作区、故障与恢复验收；适用新会话默认 Managed，延期能力原路径可用；方案、代码和指定远端分支一致 |

每步沿用设计、复现或基线、实现、相关包定向测试、build/typecheck/bundle、真实行为验证、自审及独立审查。变更推送至 `feature/managed-agents-p0-p8`，同步 companion 方案。旧实现的保留是明确的入口/配置兼容策略；未经验证的判定不得直接用于默认切换。

当前证据：M1 已交付；M2 的 PDF 物理取消缺口已在真实五阶段基线中复现并修复，build/typecheck/bundle、521 项定向测试、五阶段真实取消及独立正向读取复验通过。Gateway 转写接口仍待实现。三个普通 factory 尚未切换；MCP/Hooks 依赖判定和 Channels 入口隔离尚无实现或验收证据。

创建边界调查已确认：当前 ChannelFactory 仅接收 cwd/env，同一 Bridge 复用一个 channel，session sourceType 在之后的 newSession 才传入，因此不能只替换 factory 就按 Channels 会话分流。后续应在创建/恢复时固定并持久化执行 owner。MCP 的有效集合还包括 extension、runtime 和 session 注入；Hooks 也受 extension、trust 与 disable 设置影响，不能只读取 settings 中一个字段就声称兼容选择完整。
