# PR #9396 最终实现：live-state session activity watermark

> PR: [feat(serve): Add live-state session activity watermark](https://github.com/QwenLM/qwen-code/pull/9396)
> 状态：merged，2026-08-19 合入 `main`。
> 规模：+2451 / -55，15 个文件

## 解决了什么问题

#9261/#9366 已把 WebShell 的高频 volatile polling 从完整 session catalog 拆到 live-state，但 live-state response 还缺少会话最近活动时间。结果是 turn 完成后 WebShell 仍需要安排限频 catalog reconciliation 来更新 row recency；如果用 `catalogVersion` 表示普通 turn activity，又会让两秒 live poll 反复触发 full catalog reload，抵消 live-state 的主要收益。

## 最终实现方案

#9396 最终实现在既有 `workspace_session_live_state` capability 和 response `v:1` 下补 optional `updatedAt`，不新增 route、capability 或 readiness gate。Bridge 只在 prompt 已进入 `running` 且发布正式 terminal 时推进 per-session watermark；queue-only cancel、admission、streaming、heartbeat、attach/detach、permission/user wait 都不推进。水位写入发生在 terminal event publication 前，通过 `nextActivityTimestamp()` 保证 same-millisecond terminal、clock rollback 或 clock forward correction 下严格单调。

live-state route 直接投影 bridge-local `updatedAt`。完整 workspace session list 则通过 helper 取 live watermark 与 persisted transcript mtime 的较晚有效值，避免异步 transcript 写入把 row 排序回退；缺失或非法 timestamp 会保留另一侧有效值。`GET /session/:id/status` 仍返回 bridge summary 本身，可能早于 list 合并结果。

`catalogVersion.generation+revision` 不因普通 turn activity 递增；live-state 负责 volatile recency，catalog version 继续只表示 membership/static metadata 变化。Live task cursor/summaries 也切到新的 activity timestamp 语义。SDK/protocol/docs 仅新增 optional field，老客户端忽略即可。

## 关键代码路径

- `packages/acp-bridge/src/bridge.ts`：prompt terminal latch 前推进 per-session `updatedAt`，并投影到 `BridgeSessionSummary`。
- `packages/cli/src/serve/server/activity-timestamp.ts`：严格单调 timestamp helper 与 list merge helper。
- `packages/cli/src/serve/routes/session.ts` / `server/session-list.ts`：live-state route 与 workspace session list 的 `updatedAt` 投影/合并。
- `packages/cli/src/serve/live/live-task-service.ts`：Live task cursor 与 summaries 的 activity watermark。
- `packages/sdk-typescript/src/daemon/types.ts`：`DaemonSessionLiveState.updatedAt` optional field。
- `docs/design/2026-08-18-workspace-session-live-state-updated-at.md` / `docs/developers/qwen-serve-protocol.md`：兼容性、下游消费者与 rollout 说明。

## feature 文档处理

已在 daemon session lifecycle、capabilities/protocol、WebUI/transport、SDK 和 daemon 总览登记为 #9261/#9366 后续 merged watermark。文档明确 WebShell 请求数下降与 completion-sequence consumer handshake 已由 #9476 落地，#9396 本身只提供服务端 optional watermark。

## 边界与风险

- `BridgeSessionSummary.updatedAt` 是已公开但此前 live path 未填充的字段；下游需要继续按 optional/additive 解码。
- Ordinary turn activity 不推进 catalog version，因此静态 catalog 更新和 volatile recency 仍是两套信号。
- 持续 turn churn 的真实 daemon 性能与 WebShell consumer 请求量下降未在本 PR 内验证。
