# PR #9513 当前实现观察：PR2A restore regressions

> PR: [fix(cli): Restore PR2A session behaviors](https://github.com/QwenLM/qwen-code/pull/9513)
> 状态：open，未合入 `main`。
> 规模：+494 / -348，17 个文件

## 解决了什么问题

#9341 的 provenance 与 identity 收紧留下五项明确回归：同一拼写的 session 同时残留在 active 和 archived 时，CLI resume 能读 active copy，但 REST/ACP load/resume 会拒绝；creation metadata 读取期间发生 archive move 会误报 session not found；旧版 nil、UUIDv7 或 agent-suffixed parent identifier 会被过严的 UUID 形状检查拒绝；conversation directory 在 identity probe 之间被并发删除会被误报为 identity changed；restore 还会在锁前和锁内重复扫描 transcript catalog。

当前 PR 已主动撤回更广泛的 mixed-case Live task、session list、organization 和 scheduled-task 扩展，只保留 issue #9489 跟踪的这五项恢复行为。

## 当前实现方案

REST 与 ACP 的 load/resume 去掉锁前 persisted-id 预扫描，以生命周期锁内的解析结果为唯一权威。对请求 spelling 与存储 spelling 完全一致、且 active/archived 都存在的双副本，`assertSessionRestorable()` 明确选择 active copy，并让 writer activation 接受该状态；异拼写 case conflict、archive/unarchive 等 mutation 和普通 loadability 检查继续严格拒绝。

`SessionService.findSessionIdIgnoringCase()` 把同步目录枚举改为 `fs.promises.readdir()`，避免大型 chats 目录阻塞 daemon event loop。restore 常见的 exact-spelling 路径无需二次 catalog 扫描；若不同拼写冲突已经被识别，错误映射也不再依赖一次可能失败的额外查找。

creation metadata 不再先后探测 location，而是按 active、archived 顺序各做一次 integrity-aware 读取。creation metadata 不可变，因此 archive move 落在两次读取之间时仍能确定性命中；session id 先经过 single-segment/path-safe gate。parent lineage 移除 RFC 形状 gate，只排除 self-reference，再由 storage resolution 判断旧 parent 是否真实可读。

conversation directory identity 检查把 probe 间的 `ENOENT` 视为 already gone，`discardEmptyConversationDirectory()` 因此能在并发删除竞态下返回 false，而不是抛出误导性的 identity/permission 错误。

## 关键代码路径

- `packages/cli/src/serve/server/session-archive.ts`：`assertSessionRestorable()` 的同拼写双副本 active-first 规则与异拼写 conflict 映射。
- `packages/cli/src/serve/routes/session.ts` / `serve/acp-http/dispatch.ts`：移除锁前重复 lookup，只消费锁内权威 restore resolution。
- `packages/core/src/services/sessionService.ts`：case-insensitive catalog lookup 改为异步目录读取。
- `packages/cli/src/serve/conversations/session-source.ts`：active/archived tolerant metadata read、路径安全 gate 与 legacy parent storage resolution。
- `packages/cli/src/utils/conversation-directory-identity.ts` / `serve/conversations/conversation-workspace.ts`：目录并发消失按 already gone 处理。
- 对应 `*.test.ts` 与 `docs/e2e-tests/worktree-phase-d.md`：双副本、metadata race、legacy parent、目录删除、单次扫描和 canonical E2E session id 回归。
