## 解决了什么问题

没有本地client attachment的副本读不到resident Harness证据，恢复视图可能误把缺缓存当作不存在或缺清理义务。

## 最终实现方案

私有/session/:id/status可不携X-Qwen-Client-Id只读原resident证据，携错误client仍拒绝；原私有认证、tenant/placement/generation约束不取消。Java SDK getUnattachedStatus限UUID session/目标prompt，整次响应以2秒或原timeout较短者有界；404仅返回null，响应Session/目标prompt仍精确校验，不加载/接管、不改activePrompts。

Pool只沿当前ACTIVE placement到可达原成员读取并在返回后重核placement；external Workspace且本机无attachment的公开恢复视图才采用无附着观察。错误prompt/不可读响应产生awaiting_evidence而不是ready，无SQL证据不可绕过；显式恢复动作仍用原附着链。

## 关键代码路径

- `packages/cli/src/serve/hosted-harness-session/observation-routes.ts`：私有status允许无client观察，拒绝错client并重核原Session。
- `packages/sdk-java/qwencode/src/main/java/com/alibaba/qwen/code/daemon/HostedHarnessClient.java`：2秒有界无附着status、精确响应身份/代际校验与404空结果。
- `packages/managed-agent-server/adapters/src/main/java/com/alibaba/qwen/code/managedagent/harness/HarnessPoolConnector.java`：沿ACTIVE原placement读取，返回后再核placement不变。
- `packages/managed-agent-server/adapters/src/main/java/com/alibaba/qwen/code/managedagent/harness/QwenHostedHarnessConnector.java`：仅external Workspace且无本地attachment时只读原resident status。
- `packages/managed-agent-server/control-plane/src/main/java/com/alibaba/qwen/code/managedagent/session/SessionRecoveryService.java`：SQL证明与附着/无附着证据的保守公开投影，隔离显式恢复动作。
