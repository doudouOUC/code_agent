# PR #18132 最终实现：未准入取消后的 Session 恢复证据

## 解决了什么问题

最近一个 SQL Turn 在 Harness 准入前取消时，以它的 prompt 强行查询会挡住更早已接收输入的恢复或清理；撤回 submission 标记也不能证明 Harness 从未接收。

## 最终实现方案

抽出 cancelledBeforeAdmission：CANCELLED、无 submissionAttempted、无 Harness event epoch。此形状向 Harness.inspectRecovery 传 null，让 Harness 报最后 accepted input；明确目标时仍要求 prompt 相同。无证据不开放 next Turn，初始 pristine journal 的原就绪证明保留。

recheck 对这种本地取消只在证据为 cleanup_pending、inputSettled、continuationReady 且返回非空 prompt 时，清理那个持久目标；不能把本地取消的 prompt 或无目标状态当作清理对象。OpenAPI/生成类型调整 recovery turnId 描述，CLI 回归证明无指定 prompt 时看最后 accepted input；本 PR 未改 CLI 恢复生产逻辑。

后续 main 的18212允许本地未准入取消穿过旧cleanup欠账，但不清债务或跳过本页Session恢复证明。
