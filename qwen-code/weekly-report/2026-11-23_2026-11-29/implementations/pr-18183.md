## 解决了什么问题

根规则混杂 MySQL 命令，重复模块约束；仅依赖 wrapper 退出或 pgrep 文本匹配删除 datadir，可能误判仍存活的真实进程。

## 最终实现方案

最终3个 Markdown 文件将通用一次性服务要求留根 AGENTS，MySQL 规则移到 managed-agent-server README 的 Disposable MySQL safety，并从模块 AGENTS 链接。强调服务自身 log、有限 RLIMIT_FSIZE、start/stop 配对和 PID 文件，未知存在性 fail closed，进程确认消失前不删 datadir。

澄清 bash/dash 的文件限制块单位、限制也影响数据文件，足够大才不误杀合法增长；pgrep 只匹配 argv，是辅助扫描而非存在性证明。提供 exec/PID 和 EXIT/INT/TERM 示例，但不把文档样例当成新自动清理实现，也不声称本次运行过 MySQL 或证明任意 PID 场景安全。
