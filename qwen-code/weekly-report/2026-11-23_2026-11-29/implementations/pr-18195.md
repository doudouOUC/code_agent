## 解决了什么问题

常量和测试称36 code points，实际 requireActor 用 String.length，补充平面字符用例因此与真实准入条件相反。

## 最终实现方案

仅把 MAXIMUM_ACTOR_CODE_POINTS 更名为 MAXIMUM_ACTOR_UTF16_UNITS，继续使用原 String.length()>36 及尾部空白拒绝，不改变生产准入算法或 schema。

测试明确36个BMP汉字可通过、37个拒绝，补充平面字符18个等于36 UTF16单元、19个拒绝；内部空格仍保留。它不是把 Actor 契约扩大到36个任意 Unicode code points。
