# PR #18419 最终实现：保留 wake Action 的完整 prompt ID

## 解决了什么问题

monitor等wake prompt可超过64字符，停靠请求或SQL证书若截短/拒绝会破坏原Action相关身份并阻断恢复。

## 最终实现方案

ParkedTurn校验、JournalWriterLifecycle准入及V1的wake_seal_parked_prompt_id/record.prompt_id统一上限128，不哈希重写原ID，不改普通Turn的创建身份。V1原地重建，不添加升级迁移。

扩展真实进程矩阵覆盖图片、command、background/monitor、child和channel/pr_event等审批等待；这是测试定义，不是本次验收。同步Failsafe fork12282秒、Verify216分钟、job339分钟并更新workflow元测试，增加420秒为待首次Linux计时的预留，不宣称性能改善。

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/JournalWriterLifecycle.java`：parked prompt原身份校验上限改为128字符。
