# PR #18234 最终实现：MCP owner 回收排除 Action 停靠证书

> PR: [fix(managed-agent): keep an Action-parked Session's MCP owner from reclamation](https://github.com/QwenLM/qwen-code/pull/18234)
> 状态：merged；已合入 main，merge `4b9cc0e6906d`，最终 head `735bec3fc6d7`；对照 main `be11490df47e`。
> 规模：+54 / -7，4 个文件

## 解决了什么问题

连接空闲回收若仅看SEALED，可能把正等待审批的MCP原目录/连接回收，破坏固定continuation。

## 最终实现方案

JdbcParkedMcpOwners.sealedFor 增加 wake_seal_parked_prompt_id IS NULL，有Action证书时返回空证明。原回收job的普通idle和expedite路径都消费此证明，不能因已过idle窗口就回收。

acquire仍清证书，之后可重新走原回收条件；不新建DDL/配置。本PR实现18186当时仅文档要求的guard，但真正Hooks/MCP批次资格和保存/恢复逻辑由18236实现。

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/JdbcParkedMcpOwners.java`：查询回收证明时排除持Action停靠证书的owner。
