## 解决了什么问题

LocalStorageOwners把queryForList中physical_id直接强转byte[]，在当前VARCHAR身份返回String时会在Workspace登记前置失败，停靠验收尚未到目标行为。

## 当前实现方案

当前 open diff，不能作为 main 能力承诺。将同host、LOCAL/SSH_LOCAL的FOR UPDATE扫描改ResultSet callback，通过ManagedSchemaRows.identity统一按UTF8读取physical_id，再与physicalKey字符串比较；只对不同物理owner检查双向root重叠，保原host-domain锁、条件、冲突码和事务范围。不是放开重叠目录或schema升级。

同一候选扩展HostedPublicWorkspaceIT：version0公共Shell在publication开/关各Allow/Deny，显式核public_child_agents_version=0；Deny还核零execution。保已有children矩阵，其中只有children Allow继续测试Spring重启。main仍是原读取，候选测试新增不算验收通过；需既登记回归又端到端停靠链验证。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/LocalStorageOwners.java`：候选统一physical_id读取，保物理owner重叠目录拒绝。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/managedschema/ManagedSchemaRows.java`：ResultSet.getBytes与严格UTF8身份解码共用边界。
- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/HostedPublicWorkspaceIT.java`：version0两lane Allow/Deny及已有children矩阵。
