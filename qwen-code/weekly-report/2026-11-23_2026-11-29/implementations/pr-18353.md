## 解决了什么问题

最终diff解决Store仍按旧形状拒绝Shell/Hook/MCP continuation及publisher在旧writer下无法安全替换的问题；早期登记读取补丁已退出本PR，不能继续按标题推断实现。

## 最终实现方案

最终七文件不再包含LocalStorageOwners。ManagedHostedRecoveryRecords从原资源闭包读取固定definition，校验public Shell profile/captureBytes及UUID或null publicationId；Hook结果只允许有序且不重复的PreToolUse/PermissionRequest和digest，拒memory/command混合。持久MCP/components owner须匹配prepareReference、原prompt/call/digest/key，provider pin仍只允许单question。

Shell创建publisher时传当前writer generation；worker即使未启Runtime observation也保generation水位，同代可重放、新代可替换、旧代或无代降级/脱离被拒。增加version0两lane验收定义与闭合parser测试。不能把撤出的身份读取修复记作本PR最终交付，也未独立运行真实验收。
