# PR #18212 最终实现：cleanup 欠账下允许本地未准入取消

> 规模：+67 / -22，4 个文件

## 解决了什么问题

前序输入仍欠 Runtime cleanup 时，新Turn可能已经尝试派发却没有准入回执；即使原journal能证明它未被接收，旧空闲门仍会挡住安全本地取消。

## 最终实现方案

cancelUnadmittedTurn 的 requireIdleJournal 调用允许 allowOwedCleanup=true，仅豁免旧输入的cleanup欠账。原门仍要求CANCELLING、原dispatch owner、submissionAttempted=true且无Harness event epoch，锁定Session/head后确认writer已SEALED或租约过期。journal返回accepted集合；若含当前prompt便保留真实准入结果，不用取消覆盖。仅证实不在集合时撤回submission标记，再沿原本地取消路径结算，不能仅凭缺回执推断未执行。

旧cleanup证据和债务不因此清除，也不凭本地取消判下一Turn已ready。该改动补充18132的Session级恢复查询，而不是替代其完整证据门。
