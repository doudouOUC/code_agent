## 解决了什么问题

四个固定diagnostics字段散落在Map.get调用中，重构若顺便收紧值类型会改变历史持久结果和Tool v4确认摘要。

## 最终实现方案

RuntimeToolMeasurements.Metadata为protocolVersion/executionProtocol/measurements/resultDigest四个Object字段。读取仍只核精确键集合，不新增值验证或数值类型转换，历史Long、null及原本可读值保留；wireValue在原边界取递归不可变Map快照。记录刚构造时本身并不深冻结任意Object。

ToolExecutionRecord、repository和JDBC观察附加链改用命名参数，重复附加仍按wire JSON相等性核对；HTTP acknowledge改读resultDigest()。SQL、JSON字段和结果摘要不变，没有新协议版本或业务表。测试定义核旧数字类型、缺失测量null、未知键拒绝、wire深快照；不称为测量性能提升。
