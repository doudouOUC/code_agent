# PR #18443 最终实现：RELEASED 接管终止旧 writer lease

> PR: [fix(managed-agent): End released writer leases on takeover](https://github.com/QwenLM/qwen-code/pull/18443)
> 状态：merged；已合入 main，merge `2173fd248945`，最终 head `01db4069e13b`；对照 main `95502a5c27b9`。
> 规模：+32 / -7，4 个文件

## 解决了什么问题

已释放placement可提前接管，但若接班者不获取新writer，旧future lease会残留，接班者再离任时阻碍回收。

## 最终实现方案

在原placement takeover锁和released/expired证明通过后，仅RELEASED分支将writer_lease_until设为LEAST(旧值,DB now)。保generation/token/epoch身份、不延长已到期lease，不以普通网络失联截断活writer。测试保接管后不acquire也能继续证明旧lease已终止。

- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/persistence/HarnessPlacementStoreTest.java`：RELEASED接管不acquire仍结束旧lease的回归定义。
