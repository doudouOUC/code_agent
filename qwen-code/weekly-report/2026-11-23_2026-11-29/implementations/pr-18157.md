## 解决了什么问题

停靠返回 undefined 无法解释常驻原因，生产者未捕获 continuation 的等待甚至不注册；停靠和冷恢复各维护形状条件容易漂移。

## 最终实现方案

新增 typed refusal：区分捕获失败、Hooks/MCP/无 tool owner、command-step、输入/能力/原 prompt/审批 selection 等。hostedApprovalResumeShapeRefusal 供停靠资格、resident redrive 和 takeover 共同调用；lineage/wake-owned 等更严停靠条件仍单独保留。

captureNativeBatch 返回 DurableRef 或具体拒绝，所有持久等待都注册；不可停靠者携拒绝及永远 false 的 freeze，不能因统计接线变成可停靠。WeakSet 按 registration 生命周期只计首个拒绝一次，长等待多次检查不放大占比；suspensionStats() 返回 parkRefusals 副本。command-step 仍记拒绝，Hooks/MCP 和现有证书门不放开。后续 #18173 才把统计接到内部 metrics 路由。

## 关键代码路径

- `packages/cli/src/serve/hosted-action-parking.ts`：等待注册、类型化拒绝与共享形状条件。
- `packages/cli/src/serve/hosted-harness-session.ts`：停靠资格、恢复入口及该增量的主接线。
- `packages/cli/src/serve/hosted-workspace-tool-turn.ts`：continuation 捕获与等待冻结注册。
