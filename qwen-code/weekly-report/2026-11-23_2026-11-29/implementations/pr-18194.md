## 解决了什么问题

wake 输入没有协调器 ma_turn 行，不能套用普通 SQL Turn 的停靠/CAS模型；保 pending 又会被旧资格当作未清工作。

## 最终实现方案

新增 wakeActionParking grant 复用既有 actionParking 开关；native、可恢复来源且无其他 unsettled 输入时允许 wakeOwned。seal 使用 pending=true、dueAt=wakeAt、parkedTurn.owner=wake；V1 新增 nullable wake_seal_parked_owner，表数不变，不为 wake 造 ma_turn。command-step wake 仍拒绝。

Store 严验 owner 只可 null/wake，pending 与归属必须一致。普通 park 需要唯一 SQL Turn，wake 证书则要求零 active SQL Turn及原 revision/approval/无其他 prompt Action；acquire 清 owner，审批变化由 dueWakeParks 使 head 可扫描。cleanup 扫描排除完整证书，恢复视图区分这种 certified hold，不把它一概报 operator_required。后续18203再加入 channel/pr_event 来源。
