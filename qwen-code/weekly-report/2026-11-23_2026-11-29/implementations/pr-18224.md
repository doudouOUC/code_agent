# PR #18224 最终实现：子 Session 审批等待停靠与 relay 重试

## 解决了什么问题

有lineage的子Session已能冷恢复，但资格仍拒停靠；父relay若把reload中暂态当失败会消耗消息重试预算。

## 最终实现方案

移除停靠资格及typed refusal中的lineage专属拒绝，保原批次/输入/owner/证书条件。子Session本身有ma_turn，可复用原SQL停靠模型；不连带实现没有Action的父等子停靠。

SessionMessageRelay 对typed HarnessHttpFailure的hosted_session_closing/open_busy在原lease下安排重试、不增加attempt；其他失败沿原defer。测试定义覆盖child question冷恢复交还mount、等待中Harness死亡后审批接管，以及停靠超过relay消息Turn等待边界仍能收敛。
