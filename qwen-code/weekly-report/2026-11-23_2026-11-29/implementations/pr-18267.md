## 解决了什么问题

固定JSON形状在多处以Map取字段，协议/状态拼写及定义投影容易分歧；不能为类型化顺便改存储wire或把动态metadata封死。

## 当前实现方案

当前 open diff，不能作为 main 能力承诺。RuntimeExecutionStatus用State枚举及不可变result快照，闭合state/result字段，settled当且仅当有对象result；Broker canonical边界复用parser，v3前置投影仍保原宽容/冲突分类。ManagedContext Boot/Ready命名记录保现有闭合parser与v2 wire，toString不回显token。

SessionModelConfig内部Value/Generation替代Map，显式wireValue保字段名、缺省与空generation区别、数值规范化/8192字节门及digest。AgentDefinitionCompiler.Compiled承载model/instructions/skills/MCP/hooks，connector每次create/load投影一次；fromPinnedContent不重新应用当前allowlist，保原Session固定选择。动态result、Hook catalog、extensions等仍保开放Map，未改SQL schema或JSON存储格式；敏感key/token保持redacted。
