## 解决了什么问题

设计对Hook owner和启动Hook重放的假设未核实，可能据错误前提开放无法恢复的等待。

## 最终实现方案

四文件只有双语设计和两个测试模块。设计区分配置作用域extensions-components owner与activation owner：前者非终态close可交还mount后以同id重取，后者释放后的跨代恢复不能据旧id假定成功。

新增模型测试断言resumeFromToolResults不重触发SessionStart/UserPromptSubmit；恢复历史看到已接受prompt，而非只用于线上请求的首次Hook改写。Session测试核带Hook的command-step交还mount/同owner恢复及已完成PreToolUse不重跑。原生Hooks/MCP覆盖由后续18236另行实现，不由本PR测试代替。
