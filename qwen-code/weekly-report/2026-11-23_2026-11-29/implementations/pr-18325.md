# PR #18325 最终实现：Java 类型引用与显式 import 整理

> PR: [refactor(managed-agent): Simplify Java type references](https://github.com/QwenLM/qwen-code/pull/18325)

## 解决了什么问题

生产Java大量全限定类型名藏在注解、签名和表达式中，增加阅读噪声；简单替换又可能把同名SDK/服务契约类型混淆。

## 最终实现方案

200文件含197个生产Java文件、双语设计和class-size ratchet。缩短可无歧义解析的类型引用，补显式import；同包/java.lang保隐式引用，SDK与服务契约同名HarnessRuntimeRecovery保必要全限定名。反射类名、Spring扫描字符串、SQL及协议字面量不改。

行数门禁仅按新增import/空行等调整指定pin，ManagedSideQueryStore到800行新增pin；AgentSessionPolicies/AgentTurnExecution注明base已超一行，不是引入新业务分支。设计建议无debug编译后逐字节比较class，本次未编译也未宣称字节码等价；本次仅对全部Java文件做词法归一化与字符串保留核验，不能代替类型解析/消费者测试。

- `docs/design/2026-11-25-managed-agent-java-imports.md`：歧义类型保留与编译字节码等价验证计划。
