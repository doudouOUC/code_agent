## 解决了什么问题

托管首页只能创建空目录，不能选择已授权项目；刷新或重选也容易丢失默认 cwd。工具执行虽然已有原生日志，页面缺少与原调用关联的及时进度，且固定 16 轮模型循环会让正常长任务失败。

## 最终实现方案

Java 新增 `/api/agent/web-shell/v1/workspaces/directories/query`，只允许当前 OWNER 的 ACTIVE ROOT、已验证 LOCAL storage。按 canonical 相对路径检查目录，排除符号链接、控制字符、`.git` 与 `.qwen-child-workspaces`，最多扫描 1024 项、返回 100 个直接子目录并标 truncated；扫描后再验原 storage 身份。该授权接口可返回执行宿主根路径，不是浏览器访问任意本机目录，也不开放 SSH/CSI 浏览。

既有 create 同时接受 sourceWorkspaceId/cwdRelative，actor-scoped WORKSPACE_CREATE 回执固定名称、源 Workspace generation、storage 与目录。pending 恢复及最终事务重新核验源授权/身份；最终只建逻辑 Workspace/OWNER 并继承 config/policy，不复制项目、不新建目录或重复注册 storage。completed 重放检查新 Workspace 当前可读权限，不恢复撤权。别名仍共享 storage 访问范围和 physical-owner lease，子目录不是隔离根。

摘要增加 defaultCwdRelative/canSelectDirectory 与独立 capability；默认 cwd 从原 completed receipt 恢复。WebShell 复用 AddWorkspaceDialog，先持久化原创建键/目录，再发送；保留当前选择、草稿与未确认意图，重新选择恢复默认目录。放弃只清本地 pending，不证明服务端未创建。

`hostedToolProgress` 从已提交 tool.intent、tool.receipt 或 tool_result 消息，按原 batch/ordinal/execution 解析 call ID、名称和状态，再经 HarnessEventProjector 转为公开进度。该 feed 不带参数或完整输出，不绕过 publication reader。重放不重置工具 startTime，完成时对齐最终 assistant 时间；成功完整结果收起时不重复显示摘要，失败/partial/unavailable 保持可见。

模型轮数改读 Config.getMaxSessionTurns，正值触顶或收到 MaxSessionTurns 事件时给出独立 hosted_turn_limit_exceeded；非正值不施加该轮数上限，取消、deadline 与恢复屏障保留，不再硬编码 16。

## 边界与风险

- 源目录选择不提供子目录文件系统隔离；原 storage fence/物理 owner 仍统一。
- 不新增自动停止、取消成功或完整输出获取保证；进度是已提交执行状态的投影。
- 本 PR 不提供后续 #14442 的 macOS native identity，当前 main 的平台扩展由该独立切片完成。
