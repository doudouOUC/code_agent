## 解决了什么问题

仅保留 Pod 不能防止重叠 Session、旧上下文复用或存储被错误重新分配。公开文件会话需要在关闭后保留同一环境和文件，同时撤销原逻辑执行权限。

## 最终实现方案

管理员显式映射 tenant/Workspace/generation、精确 CSI registration、保护身份、不可变镜像/命令及可选产物；单独登记 CSI 不启用执行。重复 Workspace/alias/physical volume 拒绝，必须 files/Workspace isolation，并与 local mounts、creation roots、子环境共享及本地恢复模式互斥。调用者不能选 Pod/PVC/endpoint。

复用普通 CSI managed-context boot 与原 seed/handle/reservation。创建锁真实 Workspace，拒绝任何未完成 public Session 或未 RELEASED Runtime Session；worker 仅准入一个可撤销文件上下文，工具限定 Read/Write/Edit。旧上下文失活后不能再激活，下一 Session 可选新 cwd；没有 Shell/MCP/Hook/后台或会话内 cwd 变更。

关闭结清 Hosted journal、原执行并释放原 Harness 的持久 Runtime Session。核对共享 binding/generation/lease/owner、所有原执行 SETTLED、逻辑上下文 RELEASED 及原 CSI reservation，保留 READY binding 和 Pod/PVC/物理 owner。适配层物理 release 明确拒绝，不用关闭成功证明卸载或卷复用。释放未知保留 reservation，阻止下一 Session。

应用/Broker 可从数据库重载原身份；Pod 丢失/替换/重启、mount 改变或恢复歧义保持不可用，不自动重建。受限 DNS 注入纳入 Pod spec digest，不接受任意额外字段。无新迁移；复用当时 V1–V5，当前 main 另已有 #14323 的 V6。

## 边界与风险

- 不是自动物理退役、collector、CSI 卸载证明、跨 Workspace 安全复用、多写或 lost Pod 自愈。
- Session 关闭后 Pod/节点/存储继续计费，资源删除与付费部署须另行授权；本次没有执行这些动作。
