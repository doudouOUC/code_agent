## 解决了什么问题

私有 CSI SQL authority 与普通 Hosted `/session` owner 不兼容。文本生产若误走 public create/load 或 close，会替换原 writer、seal 原 authority 或误释放 Runtime；需要受控附着原 Session 并将普通模型文本写回原日志，而不提前开放工具和生命周期。

## 最终实现方案

Hosted-only 配置 `QWEN_HOSTED_CSI_SESSION_STORE_URL`，配合原 Broker URL/token，挂载认证且 primary-listener-only 的 `/session/:id/internal-csi/attach`、`text`、`history`。Session 必须 canonical lowercase UUID；owner map 排斥普通 Hosted 冲突，原 Session key/writer token fingerprint 相同才允许原 attach 重试。普通 route 对已附着私有 owner 的大小写变体也拒绝，不转成普通 Session。

attach 从 Broker acquire 原 Session/runtime UUID bootstrap，验证 tenant/Workspace/private capability/isolation/cwd 与 binding generation 1，创建 HTTP SQL store 和 writer generation 1，保存原 definition/root，以 requireNew 和 activation epoch 1 打开 authority。activation 有 60 秒租约、20 秒续租；text/history 前再次核验原 admission 和 assertWritable。失去租约则阻塞 owner、abort 当前 prompt 并 stopLocal，不以 close/seal 代替停止本地写入。

文本限定非空且最多 16 KiB、canonical prompt UUID、单一 active Turn，不接受 TurnBudget directive。先持久保存原 input/admission 再提交；同原 prompt 与相同文本重试原结果，改文本冲突。`hosted-csi-text-turn` 复用模型文本生产，但不安装 toolTurn；history 只暴露已结算用户/完整 assistant Parts、text delta 与 turn_result，未完成用户输入不冒充正式历史。持久化失败抛错并阻塞，模型运行错误可按原 authority 记录错误。

`HttpManagedSessionStores.stopLocal` 停续租、等待已发续租结束、拒绝新请求，但不调用 seal。owner shutdown 等待本地初始化/活动任务收敛，不调用 authority close、Runtime release 或替换 writer。`WorkspaceCsiHostedMain` 由 operator 固定原 registration/Session/request，验证 HTTPS 或 loopback HTTP origin、原 Harness boot 与 no-store response，然后只 attach/text，不新增公共产品入口。
