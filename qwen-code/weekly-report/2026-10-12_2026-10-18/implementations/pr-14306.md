## 解决了什么问题

Hosted 初始化 Core 本地 registry 后替换为远程工具，却未同步 prompt snapshot。无工具或五工具会话仍可能指导模型调用不可用 search/Agent；只改变 Config 不会刷新 chat 缓存的 system instruction。

## 最终实现方案

每轮解析一次实际声明，装入同一 chat tools；新模型请求把非空名称集合写入 setPromptToolSnapshot，空工具用显式空集，不是 undefined。Hosted 不开放本地 deferred bridge，只有声明 agent 时才设置 Agent 可达。按集合成员而非顺序判断变化，名称或 Workspace context 改变时合并为一次 refreshSystemInstruction；schema/description 仍逐轮更新 tools，不强制重复渲染提示词。

preparedRecovery 仍调用原 Turn.run 及保存的 prepared request，不以新 context/tools 重写原请求；进入下一个 fresh round 才同步。声明解析或 prompt refresh 失败则不开始新 inference，Agent 指令位于项目 context 之前的原拼接顺序保留。新增边界单测和真实 Hosted→本地 mock OpenAI wire 的集成测试，区分工具 schema 与指导/示例过滤。

## 关键代码路径
