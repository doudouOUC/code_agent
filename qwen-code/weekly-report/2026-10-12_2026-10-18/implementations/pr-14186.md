## 解决了什么问题

Managed server 的 Checkstyle 配置与实际代码风格不统一，测试源码未纳入同一静态门禁；只依赖昂贵的 MySQL/host-lock verify lane 还会让静态检查长时间无法获得运行机会。

## 最终实现方案

新增 qwencode/qwen-code-checks.xml，规定 LF、空白、brace、缩进、import 分组、命名、modifier、override 和基本代码结构。Managed server pom 的 configLocation 切向该文件，并显式 includeTestSourceDirectory=true；这不等于所有 SDK/Broker Maven module 都已切换。生产与测试源批量重排 import、添加 brace/调整语句布局，未新增 Hosted API/schema。最终 workflow 在 Ubuntu/Java21 增独立 server checkstyle:check，不依赖 sibling install/MySQL/host lock，但并不改变 workflow 的 schedule/dispatch 触发性质。
