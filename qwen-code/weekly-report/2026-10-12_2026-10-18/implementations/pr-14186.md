## 解决了什么问题

Managed server 的 Checkstyle 配置与实际代码风格不统一，测试源码未纳入同一静态门禁。新配置及 import/brace/空白等批量调整旨在统一规则，但不能用 PR 标题“fix all”认定通过；错误的自动加括号还会破坏 Java 语法。

## 当前实现方案

新增 qwencode/qwen-code-checks.xml，规定 LF、空白、brace、缩进、import 分组、命名、modifier、override 和基本代码结构。Managed server pom 的 configLocation 切向该文件，并显式 includeTestSourceDirectory=true；这不等于所有 SDK/Broker Maven module 都已切换。生产与测试源批量重排 import、添加 brace/调整语句布局，未新增 Hosted API/schema。

精确 head 中 `BrokerSecurity.hostOf/isLoopback` 把花括号插入三元式和 substring 参数，`SessionLifecycleCoordinator` 的 blocked error-code 三元式也被破坏。本次用 JDK 21 JavacTask.parse 对这两份生产源做独立语法探针，分别报告 7 和 3 个解析错误；这是有限两文件证据，不是全仓编译、Checkstyle 或测试结果。当前 head 因而不能按“纯格式且可构建”记录。
