> 规模：+5,070 / -283，35 个文件

## 解决了什么问题

#10574 允许同一 owner 的命名 tasks 并发运行，但它们仍共享一个 workspace checkout。两个 task 同时编辑 Git 工作树会带来文件、index 和 branch 冲突。同时，worktree 不能只靠 catalog 中的 cwd 字符串恢复；重启后必须证明 sidecar、marker、canonical path 和 exact session owner 仍一致，否则宁可失败也不能误接到 shared workspace 或他人 worktree。

## 当前实现方案

Channel 命令增加精确 `/session new <name> --worktree`。worker 只在 daemon 宣告 `session_worktree_persistence_v1` 时请求 worktree；旧 daemon 不做不可验证的 fallback。daemon 创建 worktree 并取 canonical realpath，将 exact session relocate 到该 cwd，确认 child 返回 cwd 一致后，排他创建 `.qwen-session` marker（`O_EXCL`/`O_NOFOLLOW`、0600、regular single-link、inode/device 稳定、最大 512 bytes），再原子写 sidecar。只在两者成功后 response 才带 `worktreeState:'persisted-v1'`。

restore 路由主动禁用泛化 worktree context restore，自己严格读取最大 64 KiB sidecar，拒绝 symlink/hardlink/invalid data，并校验 workspace/repo root、realpath 在 `.qwen/worktrees` 下、marker owner 等于 restored storage session ID。latest head 将 restore AUQ prompt 暂存到 worktree integrity/relocate 完成后才触发；对于刚恢复且 prompt 状态存在、但 child 尚未报告 cwd 的 session，只登记内存 worktree metadata，不提前发 `persisted-v1` attestation。active session 已有 cwd 时必须精确匹配，idle session relocate 后也必须再次匹配。任一证明不稳定时丢弃 deferred prompt、清理 attachment/cold restore 并 fail closed，不 fallback shared workspace。

SDK/bridge/router 只在 daemon 返回 exact attestation 后记录 canonical worktree path，named catalog 增加 `isolation:'shared'|'worktree'`。创建失败用 orphan-guarded exact session delete；只有证明 session 已删除才可清除 checkout/branch，所有权不确定时保留工作树。selected worktree task 中 `/clear`、`/new`、`/reset` 在取消或状态变更前拒绝；close 保留 transcript/worktree，不做物理删除。

## 关键代码路径

- `packages/channels/base/src/named-session-manager.ts` / `ChannelBase.ts`：isolation catalog、创建语法、restore reservation 和 reset guard。
- `packages/cli/src/commands/channel/daemon-worker.ts` 和 `packages/channels/base/src/DaemonChannelBridge.ts`：capability gate、worktree request/attestation 和 canonical cwd 发布。
- `packages/cli/src/serve/routes/session.ts` 及 daemon service wiring：worktree create/restore/relocate、deferred AUQ admission、failure cleanup 和 response state。
- `packages/acp-bridge/src/bridge.ts` / `bridgeTypes.ts`：按 client 暂存、触发或丢弃 restore AUQ prompt，避免在 worktree 证明前启动恢复 turn。
- `packages/core/src/services/gitWorktreeService.ts` 和 `worktreeSessionService.ts`：strict marker/sidecar creation、read/validation 与 containment。
- `packages/sdk-typescript/src/daemon/DaemonSessionClient.ts` 和 `types.ts`：worktree request/result metadata 与 exact reattach validation。
