## 解决了什么问题

#10751 已交付 session-wide sparse turn index和 snapshot-bound random-access transcript read，但 WebShell当前只有 append/prepend flat transcript store。任意中段 page无安全落点，淘汰范围没有 gap，message层还丢失 `sourceRecordIds`/`promptId`，因此 rail完整性继续依赖已加载并保留的 messages。

## 最终实现方案

最终 docs-only设计保留 `DaemonTranscriptStore` 作为渲染源，在 provider内提出 immutable transcript page ledger、显式 gap、独立 live tail和 turn-index store。已有 isolated materialization、atomic `store.reset()` admission与 prefix trim继续复用；新增 insert-at-ledger-position处理 anchored page和 newer continuation，避免把不连续记录拼成连续 transcript。

turn index先加载 newest metadata page并独立分页旧 metadata。消息转换层保留 persisted record/prompt identity，建立 turn到 block/message locator；provisional live turn只按 exact prompt/record reconcile。`openTranscriptAtTurn()`使用产生该 entry的 snapshot进行 anchored read，隔离 materialize并去重后按整页原子 admission/eviction，区分 `page_too_large`、`window_full`、`window_impossible`。旧 daemon、缺 capability或 index超限继续使用 loaded-message rail。
