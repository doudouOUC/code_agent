## 解决了什么问题

Managed 输入框没有已发布 Skill 列表，用户输入 /skill 也不能保证先加载原定义中的指令。

## 最终实现方案

原切片中 WebShell 在菜单打开时按 provider/Session 延迟查询，切换时取消旧请求；Java 先检查可读 Session，再返回其固定定义的名称/描述，READ profile 或无定义返回空集，不扫描宿主 Skills。

HostedSkillCatalog 只解析连续前导、确实存在的 /name，去重并遇到未知名称停止。仅首次、非 model/tool-result 恢复且有 toolTurn 时，生成原生 client-initiated skill 调用，交给同一个工具 Turn 执行，随后以 ToolResult 进入模型；静态 skill 加载纳入 Plan 只读集合，不绕过原工具授权。

后续已合入 [#14930](pr-14930.md)：当前目录优先原创建 receipt 固定的 Skills 快照，无快照才回读原定义；内置 qwen-code Session 也可创建时导入启用的正文。model_invocable/user_invocable、原 clientInitiatedSkills 与结果预算共同约束新建、调用和恢复，不运行时重扫宿主，不复制 assets。
