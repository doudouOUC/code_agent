> 规模：+705 / -233，15 个文件

## 解决了什么问题

数据库 integration test 串行耗时，而同一 MySQL server 上的不同 schema 仍共享全局 deadlock counter；简单并行会制造互相干扰，重复执行无关门禁也会拖慢 Java 迭代。

## 最终实现方案

mysql-integration profile 保持默认 forks=1，显式 mysql.integration.forks 可调，reuseForks=true、JUnit parallel=false，并排除 Hosted* 以保持 lane 分工。JUnit launcher listener 在应用初始化前，把 mysql.url.<fork> 路由到当前 fork 的 mysql.url；校验 fork 范围与 jdbc:mysql://。0${surefire.forkNumber} 保留 Surefire 运行期展开，避免 Maven 过早替换。

CI 的 MySQL/MariaDB 各创建两个独立 server/container，不是只分两个 schema；各自 URL、端口与 readiness，传 forks=2 并保留 legacy URL 兼容。两个 server 均设 max_allowed_packet>=134217728、tmpfs/适配配置，MySQL 禁 log-bin；任何启动/测试失败都清理两个原 owned container，第二个失败不跳过清理。

模块 AGENTS 明确 changed-behavior focused validation 与最多共享 10 分钟本地预算（包括 setup），不无条件重跑 full verify；匹配 source 的 sibling SDK 使用隔离 Maven repo，真实 DB/独立进程证据与 H2 分开，CI 仍负责完整 suite。当前 main 后续 workflow 的其它预算调整不属于本 PR 的生产能力。

## 验证方式

本次独立核对最终 diff、完整 changed files、关键调用与最新 main；未运行源码、浏览器、真实模型、MySQL/OSS/CSI/SSH/native 或部署门禁。以下是验证入口，不是本次执行通过声明；Java 按源 AGENTS 预检、安装匹配 sibling SDK 并遵守本地聚焦验证预算，进程 fixture 先构建匹配 Core/CLI。

根目录 `node --test scripts/tests/hosted-process-ci.test.js scripts/tests/sdk-java-workflow.test.js`；Java：`mvn -Dtest=MySqlForkRoutingListenerTest test checkstyle:check`。真实 MySQL/MariaDB lane 需在两个 disposable server 就绪后按 workflow 传独立 mysql.url.1/mysql.url.2 和 mysql.integration.forks=2 执行；单 server 双 schema 不能替代。
