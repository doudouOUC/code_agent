## 最终实现方案

最终 diff 只有两组中英设计/部署说明，撤出节点证据代码；公开 Read/Write/Edit 与逻辑 Session 交接来自已有 #14340，不由本 PR 新增。固定管理员/Kubernetes/宿主/合资格 CSI 驱动的信任边界，限定 ACK Disk CSI、RWOP、Filesystem/ext4 及原磁盘 serial/Pod/container/mount/registration/reservation 身份。

A 关闭只撤销原上下文，B 使用同一运行环境和文件；UNKNOWN 执行/释放保留未完成 Session 与 reservation，拒绝下一 Session，租约或对象消失不授权替代 Pod/卷交接。最终主干另由 #14765 加入显式空闲维护；设计中提及其早期 stacked 节点证据方案属于历史，不能覆盖最终实现。
