## 解决了什么问题

运行中或等待审批时只能先结束 Turn 才能改 default/auto-edit/yolo，且简单读取 mutable Session 模式会改变原 Hook/恢复的审计证据。

## 最终实现方案

原切片允许同时支持 approval-selection/1 与 live-approval-selection/1 的公开 bound files/1、shell/1、shell/2 运行中改模式；当前 #15330 已统一为 files/1、shell/1，旧 Shell/2 明确拒绝。原 owner/OPERATOR、expected revision、幂等 receipt 和 SQL 锁保留。Plan 切换及模型切换仍要求空闲；关闭、取消、恢复阻塞和冲突 operation 拒绝。用户 Turn 的原审批/Plan 快照不重写。

Hosted 通过原 writer 身份的内部 approval:query 串行读取单调 revision；缺失、回退或同 revision 异模式停止安全执行。新工具/Hook 在检查点读取当前模式，普通策略生成的待决审批在轮询确认当前无需询问时走原 Action allow；明确 Hook ask、exit_plan_mode 仍要原决策。已 dispatch 的工具不撤回。恢复 Hook 以保存的 permission_mode/摘要重建原字段，不能用新模式伪造旧输入；退出 Plan 的原 Action 可清当前 Session Plan 而不改原 Turn。

2026-10-25 当前 #15448 增 Auto 与 Session 便携规则，公共 profile 资格由当前 WorkspaceToolProfiles 决定（含 files/3），不沿原 files/1、shell/1 列表缩窄。规则只空闲 CAS、冻结原 Turn，live reader 要求规则不变；显式规则 ask/Hook ask/Plan 退出保存人工下限，不因切 yolo 自动通过。
