## 解决了什么问题

普通 Qwen Code 接受的 GIF 和 image/jpg 在 Managed 输入中被拒绝，或重载后 MIME 不一致，破坏同一附件的规范化请求。

## 最终实现方案

WebShell encode/private block/restore 与 Java normalize、Hosted parse 同步接受 GIF，image/jpg 在规范输入和模型 Part 中统一为 image/jpeg。仍验证 PNG/JPEG/GIF/WebP 签名和 canonical base64，错误 MIME、无效签名与额外不支持格式拒绝；沿既有 8 MiB 的完整编码输入和原 accepted bytes/digest。

本次不做图片转换、动图解码或新文件存储，不依赖文件名猜 MIME；图片模型能力检查和恢复权限保留。

## 关键代码路径

- `packages/web-shell/client/components/managed/managed-input.ts`：编码、恢复及 MIME 归一。
- `packages/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/session/ManagedInputAttachments.java`：Java 签名与格式校验。
- `packages/cli/src/serve/hosted-input.ts`：Hosted 相同格式与模型 Part。
