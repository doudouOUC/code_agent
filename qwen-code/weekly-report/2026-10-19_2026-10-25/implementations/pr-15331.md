## 解决了什么问题

Managed 侧栏行、操作区和归档入口与 daemon 不一致，长标题会挤占按钮；归档 Session 不在统一折叠区，用户难以辨认状态或找回会话。

## 最终实现方案

ManagedSessionNavigationRow 复用 daemon 行样式与 SessionDetailsTooltip portal，测量标题溢出、固定操作空间并支持 Enter/Space；动作阻止冒泡，pending 用固定 26px spinner 区避免跳动。tooltip 只显示 Managed 的标题/状态/时间/ID/Workspace/cwdRelative，复用 ID 复制，不伪造 daemon connection/client count。Workspace 新任务按钮 hover/focus 显示、触屏常显，移除重复 Managed/新任务模式徽标。

新增 ManagedArchivedSessions 独立读取 archiveState=archived、每页 50/cursor，按 Session ID Map 去重，加载/更多/错误重试分别呈现。provider/client/cursor/retry 变化取消旧请求，防止迟到数据污染；计数是已加载条数而非服务器总数。普通导航明确查 unarchived。

WebShell 底部只有一个 Archived 折叠区，汇总 daemon/standalone/Managed 的内容、计数和 loading；各后端仍独立读取与授权，Managed 错误不会显示成空列表。ManagedSessionsPage 只在适用 home/provider 生命周期挂载归档 portal，并保留原 Session actions/取消屏障，不增加跨后端操作 API。

## 关键代码路径

- `packages/web-shell/client/components/managed/ManagedSessionNavigationRow.tsx`：行布局、tooltip、键盘与操作隔离。
- `packages/web-shell/client/components/managed/ManagedArchivedSessions.tsx`：原 provider 分页/去重与失效取消。
- `packages/web-shell/client/components/managed/ManagedWorkspaceNavigation.tsx`：复用行与 Workspace 新任务入口。
- `packages/web-shell/client/components/managed/ManagedSessionsPage.tsx`：归档查询、portal 与原动作上下文。
- `packages/web-shell/client/components/sidebar/WebShellSidebar.tsx`：统一折叠区但不混合后端 authority。
