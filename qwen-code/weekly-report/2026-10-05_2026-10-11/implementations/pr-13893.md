# PR #13893 关闭方案观察：私有 CSI profile 与 local-process 隔离

> PR: [feat(runtime-broker): reserve the private CSI local-process boundary](https://github.com/QwenLM/qwen-code/pull/13893)
> 状态：closed，未合入；关闭前 head `2f142908f42a`，仅作历史方案观察，不能作为 `main` 已落地能力。
> 规模：+321 / -0，6 个文件

## 解决了什么问题

私有 CSI 文件执行需要与通用本机 Runtime 使用不同能力摘要、Session 隔离身份和 provisioner。若 local-process 接受这个 profile，可能在创建、恢复或操作员清理时把本机进程当成具备 CSI 挂载和原资源证据的 worker。

## 关闭前方案

`CsiFilesRetirementProfile` 固定 `csi-files-retirement/1`、Read/Write/Edit 工具集合、file-history 与 until-finalize retention，并以相同 manifest 生成 capability digest。request 要求规范小写 Session UUID、绝对且无空段/`.`/`..` 的非根挂载路径、根 cwd 和指定 contextConfigRef，再构造 `session` 隔离、`kubernetes-workspace` 和原 storageId 的请求。

`LocalProcessRuntimeProvisioner` 在解析 storage、创建/采用进程、持久注册、观察/确认、释放以及操作员证明前拒绝该 digest，返回不可重试的 409 `runtime_provision_failed`。测试同时检查 spawn marker、storage resolver 和本地注册文件没有副作用。这是拒绝错误后端的边界，不包含实际 worker 或 Kubernetes 创建实现。

本 PR 已关闭未合入；同样的 profile 与拒绝逻辑已由 #13899 合入，主干能力来源于后者。本次只记录代码重叠，不推断关闭原因，也不把本关闭 PR 写成合入记录。

## 关键代码路径

- `packages/sdk-java/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/CsiFilesRetirementProfile.java`：能力摘要与规范原 Session/挂载身份。
- `packages/sdk-java/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/LocalProcessRuntimeProvisioner.java`：所有本机 provision/recovery/release 入口的 profile 拒绝。

## 边界与风险

- capability digest 的预留不代表 Kubernetes provisioner、公共 CSI Session 或完整退休流程可用。
- 关闭方案不作为部署依据；worker 与控制面的合并状态须分别核对。
