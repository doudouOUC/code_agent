## 解决了什么问题

WebShell 无法从 Session DTO 判断已有 Java cwd operation 是否对当前用户、当前 Workspace 和当前部署可用；只凭 Session 为 ACTIVE 展示入口会遗漏 registry、generation/storage 和权限约束。

## 关闭前方案

`ManagedAgentService` 将 submit 和 cwd 两种能力形状的 creator-owned 候选合并批量查询。cwd 候选需 ACTIVE、未删除、已绑定 Workspace 且 workspaceFiles 开启；`sessionsWithExecutionRegistryFacts` 进一步核验冻结 Workspace generation/storage、活跃 registry 和 OPERATOR/OWNER grant，才返回 `cwdChange`。

ApiModels、公共 OpenAPI 和生成的 WebShell 类型同步新增可选能力字段，避免 N+1 查询。该 diff 不含目录切换对话框或客户端原 operation 恢复；#13760 当前 open diff 包含相应能力及 UI 接线，不能据此推定本 PR 关闭原因。
