## 解决了什么问题

delete、archive、unarchive 或 conflict repair 完成 transcript 主变更后，workspace runtime generation 可能立即关闭。继续用 generation fence 会中断 sidecar/organization 清理并永久留残；直接移除 fence 又可能删除 replacement writer 新建的同 session 数据。

## 关闭前方案

关闭前 diff 把 transcript 主变更前的 snapshot/generation fence 与提交后的 cleanup ownership 分开：主变更后仅在精确 writer lease 仍由原 owner 持有、lock 为同一普通文件且 raw record 未变时继续清理 worktree、PR、prompt ledger、file history 和 organization。foreign、ambiguous、symlink、malformed 或已替换 lock 均 fail closed。

该版本基于较早 lifecycle 基线，未接入 #10179 合入后的 standalone archive/delete/recovery 路径，因此关闭并由 #10300 重新实现。
