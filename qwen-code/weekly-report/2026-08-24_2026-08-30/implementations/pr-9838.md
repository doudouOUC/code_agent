## 解决了什么问题

现有 `cron_create` 会为 durable scheduled task 创建并管理独立 session。用户若希望未来触发继续使用当前 daemon 会话的上下文，没有受支持入口；直接把 task 绑定到当前 session 又会引入 ownership、并发和持久化风险，例如子会话或 Live/special source 被接管、活跃 prompt 或 pending interaction 中途转成 task、跨 workspace 复用、同一 session 被多个 task 绑定，以及持久化成功后 runtime generation 已关闭。

## 最终实现方案

最终实现给 `cron_create` 增加 optional `sessionMode: 'unbound' | 'current'`。省略或 `unbound` 保持既有独立 session 行为；`current` 必须同时 `durable:true`，并从 `promptIdContext` 取得当前 daemon prompt。Core 不直接操作 Serve storage，而是调用 host 注入的 current-session task creator；普通 CLI、未接 daemon callback 或无 active prompt 时返回明确错误。

ACP Session 安装 daemon-only private creator，把自身 session ID、当前 prompt ID 和 cron/prompt 参数交给 bridge。bridge 先验证调用 connection 确实拥有该 session，prompt ID 非空且与 active prompt 精确相等，并对 cron/prompt 长度与 shape 做界限；还要求 top-level ordinary/default source，无 parent/sourceId 或特殊来源。Serve host 再解析 owning runtime，拒绝 unavailable/ambiguous/cross-workspace owner、pending interaction、parented/sourced/already-scheduled source、已有 task binding；REST path 要求 session idle，private cron-tool path 只允许这一个精确 active prompt。

通过准入后，host 把 task 持久化为 existing-session binding，并设置 `sessionOwnedByTask:false`，从而复用既有 keepalive/rehydration/delete/scheduler 生命周期而不把用户会话视为 task 所有。mutation 带 runtime generation assertion；若 generation 在 commit 后关闭，会回滚刚创建的 task。新 capability `scheduled_task_session_reuse` 只在 host callback 与 managed runtime 支持完整接线后广告，caller-injected/partial bridge 不广告；fast-path bootstrap envelope 与 runtime-mounted envelope 因此可以暂时相差这一项。Web Shell 的 Scheduled Tasks dialog 只在 capability 存在时提供 session mode，默认仍为 dedicated；当前 session missing/busy/pending/parented/sourced/cross-workspace/already-bound 时禁用复用，并只在用户明确选择 current 后发送 session ID。

## 边界与风险

- `sessionMode:'current'` 只支持 durable task 和 daemon 顶层普通 session；子会话、Live/standalone special source、already-bound session 与普通非 daemon CLI 均拒绝。
- 创建 task 不改变当前 prompt 的执行；task 只在未来调度触发时复用该 session，仍受 keepalive、writer/runtime generation 和 active-work gate 约束。
- 默认值保持 dedicated/unbound，旧客户端、旧 daemon 和 partial bridge 不会意外复用当前 session。
