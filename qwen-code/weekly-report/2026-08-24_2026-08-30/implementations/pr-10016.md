# PR #10016 当前实现观察：LLM span 的 context usage 分类属性

> PR: [feat(telemetry): Emit context usage span attribute](https://github.com/QwenLM/qwen-code/pull/10016)
> 状态：open；以下仅描述 2026-08-26 复核到 head `0ae9d72ea8` 的当前 diff，不能视为 `main` 已落地能力。
> 规模：+1,448 / -37，13 个文件

## 解决了什么问题

现有 `qwen-code.llm_request` span 记录 provider 上报的总输入 token，却不能解释 system prompt、built-in/MCP tool definitions、memory、skills 和 messages 分别占了多少上下文，也不能直接看到距离自动压缩阈值还剩多少输入容量。`/context` 能在交互界面展示类似拆分，但运维者无法把它与一次请求的延迟、retry、cache usage、错误和 compaction 行为关联。

## 当前实现方案

当前 open diff 增加私有 span attribute `qwen-code.context.usage`，值为版本化的紧凑 JSON。`LoggingContentGenerator` 在 `generateContent` / `generateContentStream` 的同步 prelude 中、任何 `await` 之前，从本次 provider-neutral request 和 immutable context-window 配置构造 method-local snapshot；仅 telemetry SDK 已初始化且 prompt 不是 internal background prompt 时执行，采集异常只写 debug warning 并省略属性。

`createContextUsageSnapshot()` 把逻辑请求分成 system prompt、built-in tools、MCP tools、memory files、skills 和 messages 六类。文本分类复用从 `/context` 抽出的 CJK-aware estimator；structured messages 继续使用现有 `estimateContentTokens()`，避免把 inline media base64 当普通文本。memory 只有在 effective system instruction 中精确命中时才单独归因；skill body 只从 committed in-memory cache 和已加载 skill 精确 output 匹配，不触发文件发现，也不记录名称或正文。

请求开始时 span 先写本地估算。若结束时 provider 给出合法 `gen_ai.usage.input_tokens`，`normalizeContextUsage()` 保留五类固定估算；固定和不超过总量时把 messages 设为 residual，超过时按 largest-remainder 比例缩放固定类并把 messages 置零。最终六类之和严格等于 provider 总量，并计算 `max(0, window-reserve-total)`。标准 input/cache usage 字段不变；无合法总量的失败、取消或 TTL 结束 span 保留开始估算。

Schema 只包含版本、数值聚合、`estimated:true`，序列化超过 1024 字符、shape 非法或 JSON 失败时省略。它不新增 metric、log event、session attribute 或 `gen_ai.*` 自定义字段，也不记录 prompt、路径、工具/模型/session/user 名称。

## 关键代码路径

- `packages/core/src/core/loggingContentGenerator/context-usage-snapshot.ts`：从实际 request、Config 和内存 cache 构造六类 snapshot。
- `packages/core/src/telemetry/context-usage.ts`：v1 schema 校验、provider-total normalization、1024 字符序列化边界。
- `packages/core/src/core/loggingContentGenerator/loggingContentGenerator.ts`：同步 snapshot、internal/telemetry gate 与 request-local ownership。
- `packages/core/src/telemetry/session-tracing.ts`：span start 写初始 JSON，span end 用 provider usage 覆盖 normalized JSON。
- `packages/core/src/services/tokenEstimation.ts` / `packages/cli/src/ui/commands/contextCommand.ts`：抽取并复用 CJK-aware context estimator，保持 `/context` 显示口径。
