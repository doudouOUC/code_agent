## 解决了什么问题

默认 Skills 增加的 creationToolProfile 留在 AgentSessionPolicies 后触碰类规模门禁，facade 委派清单又未登记新方法，使实际默认创建行为正确时结构 gate 仍失败。

## 最终实现方案

四文件最终 diff 只把 creationToolProfile 的15行方法及所需 import 从 AgentSessionPolicies 移至 AgentSessionAdmissions，ManagedAgentStore facade 改委派 sessionAdmissions。方法仍 resolve 同一 pinned agent，原 publicShell/MCP/profile 门禁与 Workspace 创建解析不变，external Workspace 仍返回 null；没有弱化鉴权、SQL fencing 或门禁阈值。ManagedStoreDecompositionTest 的方法清单补 creationToolProfile/5::REQUIRED:DEFAULT:false，使真实 facade 面与 REQUIRED 事务契约一致。该移动也是 #17703 在最新 main 的路径演进，不计入原 PR 规模。

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/AgentSessionPolicies.java`：移除原方法及无用 import。
