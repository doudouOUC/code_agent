## 解决了什么问题

Web Shell 依赖独立 camelCase 私有路由和生成类型，Public API 缺模型/审批/能力、文件和 transcript 等 UI 所需形状，双契约持续漂移。

## 当前实现方案

当前 open diff 补 PublicSession 的 title/environment/model/approval/lifecycle/latest_turn 与 capability，创建参数接受 title/model_id/approval_mode/plan_mode；控制器按原 Service 权限、revision 和幂等键处理模型/审批变更，并补 transcript/items/export、workspace discovery/files、client-files、工具详情及 Skills 等 Public 入口。未绑定 Workspace 的创建仍拒不支持的审批/模型选择，分页 limit 保 1–100。

生成器只选非 planned 的 Public Sessions/Public Resources operation；旧 camelCase 形状冻结到 java-agent-contract-types，纯 adapter 将 snake_case wire 转回现有组件契约，只给 Session/Turn/Event/Item 的 epoch seconds 乘 1000，事件 data 不重命名，其他 family 的毫秒不重复转换。client 主前缀改 /v1/agents，同时仍有明确 WebShell 兼容入口，不能写成旧 API 已删除。local proxy 接 Public 路径但拒编码斜杠/反斜杠/点和原始 dot segment，维持签名路径边界。该候选尚未合入 main。
