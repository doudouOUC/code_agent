## 解决了什么问题

wake stamp 的数据库边界只由原 H2 fixture 覆盖，挂起放行谓词内联，无法逐条钉住非 wake、已到期、已尝试和 stopped-message 的拒绝条件。

## 最终实现方案

最终抽出 wakeDispatchOwnsInput，原 pending.some 改调共享谓词，不改变原判断：必须 wake 来源、非 stopped message、notBefore 非空且严格晚于 now、从未尝试；不满足任一项仍阻挂起。测试逐条覆盖边界，并补 HTTP client 在 acquire/renew 中保留或撤销 wakeDispatch 能力的回归。

WakeSealStampTest/WakeRecoveryStampedHeadsTest 将 DataSource 创建变为可覆盖工厂，新增两个 MySqlIT 子类用 IsolatedManagedSchemaMySqlTestDatabase 复用同一套断言，AfterEach 清理自有数据库。不是复制一套较弱 SQL 测试，也没有修改扫描周期、增加开关默认值或放宽其他 live-work 守卫。
