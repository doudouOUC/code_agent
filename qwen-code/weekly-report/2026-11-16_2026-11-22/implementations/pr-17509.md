## 解决了什么问题

按行缩进/正则提取 V1 DDL 会把多行列、generated/check 表达式或注释中的分号/逗号错误切开，使合法格式调整破坏初始化和 catalog 校验。

## 最终实现方案

ManagedSchemaDdlParser 先按顶层分号拆 statement，再以 token、引号/注释和括号深度解析 CREATE TABLE/INDEX，形成 table/column/primary/unique/index/check 规格；支持当前 V1 所需有限类型，不支持的语句/约束、重复表和非 InnoDB 声明抛 SQLException。保留 MySQL prefix index hint 处理，不是通用 SQL 引擎。

ManagedSchema 初始化也复用 splitStatements；ManagedSchemaCatalog 消费解析结果核实际 catalog，仍校验列/主键/唯一索引/generated/check。唯一 V1 只移除一行注释，本 PR 合入时46张业务表、reader 5 与旧/残缺/外来 catalog 拒绝规则不变；当前 main 后续为47表，没有新增升级迁移。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/managedschema/ManagedSchemaDdlParser.java`：有限 DDL tokenizer 与结构规格。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/managedschema/ManagedSchemaCatalog.java`：按规格核 catalog。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/managedschema/ManagedSchema.java`：初始化共用 statement splitter。
