## 解决了什么问题

外部文件 Workspace 原只支持普通文件任务，无法在保持原外部执行 actor 与受限工具面的同时提供持久、可恢复的公开子 Agent 和内容扩展包。

## 最终实现方案

以下为功能分支最终合入 diff，不是当前 main；测试命令也应在该分支或本 PR head 上核验。

新增 hosted-workspace-external-files/2 content profile，workspace-content-agents-enabled 默认 false，并继续受 public child/外部配置能力门禁约束。content-only 配置 formatVersion 2 没有独立 MCP selections、base/server MCP 或 hook catalog；不带 settingsRevision，不接受 Plan、memory、capture 或 child worktree/snapshot 等执行选项，不等于外部 Shell/完整插件执行。

资源用 manifest→page→part 的不可变闭包，逐段/逐文件核 kind/schema/长度/digest；单资源最多 64 KiB，累计最多 256 文件/8 MiB，拒绝穿越路径。ManagedContentPackageAuthorization 先核原 writer/workspace/generation，再要求 pin 属于当前、初始或父 child launch 的精确 configuration operation。ExternalWorkspaceSessionLineage 锁读父子，限定同 tenant/Workspace/generation/storage/cwd/context、同 actor、一级 child 与持久 child_run；重放核原 request digest/lineage，委托审批按父 revision 冻结，auto 降为 default。relay/retirement 按原 lineage 释放，不把 parent 当前不可用当创建新 owner 的理由。
