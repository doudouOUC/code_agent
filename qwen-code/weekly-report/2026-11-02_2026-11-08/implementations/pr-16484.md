## 解决了什么问题

根 Session 独占问答和等待时持 Workspace mount 会阻塞其他子任务；多个问题共用 UI 草稿还可能丢失或串答。

## 最终实现方案

在原根问答外，仅 definition/lineage 证明 publicChildAgentsVersion=1、depth=1、parent=root 的 shell/1 LOCAL child 扩展问题准入；MCP/Hook、foreground-only、Resident/CSI、memberPlan 与扩展 agent 不泛化。question continuation 可固定 provisionerKind=local-process 且批次只含一个 ask_user_question 调用。先持久 Action/原 input/continuation，再按原 mount claim 尝试 handback；可重试 busy/内部错误在有界首次等待后后台重试，不伪造已释放。回答/恢复重新 acquire 同 binding/generation/workspaceGeneration/provider，busy 可等待，身份不符 fail closed。cleanup 分 released/held/pending，terminal/debt 与真正 drain 分开。UI 以 Action/request/revision 逐题保存当前页面草稿和提交态，父页可定位子问题，防串答，冷重载仍查持久 pending，不承诺未提交草稿跨页面持久。

## 关键代码路径

- `packages/cli/src/serve/hosted-question-wait.ts`：限定 definition、mount handback 与原身份重获。
- `packages/cli/src/serve/hosted-workspace-tool-turn.ts`：子问题声明和 continuation。
- `packages/cli/src/serve/hosted-turn-cleanup.ts`：held 与未完成 cleanup 区分。

- `packages/web-shell/client/components/managed/use-managed-actions.ts`：逐问题草稿/提交状态。
