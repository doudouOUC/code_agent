# PR #16217 最终实现：Resident claim/release 只读检查移出租户锁

## 解决了什么问题

Resident Workspace 的 claim/release 分支只核验既有绑定，却先获取租户 placement guard；同租户其他资源维护因此会拖住原本只读的调用。删除整个生命周期围栏又会错误接纳已清空或不同身份的 Runtime。

## 最终实现方案

只在 resident 分支保留原事务和 requireResidentHeld，移除 lockDomain；检查仍核对原 slot、Runtime Session 与释放状态，不创建或替换 resident generation。只读快照之后提交的状态转换可排在本次检查之后，调用方后续执行仍依原 admission/dispatch 围栏。非 resident 成员准入、placement、drain 和物理释放协议没有由此统一去锁。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/WorkspaceExecutionStore.java`：resident claim/release 的事务与身份核验。
