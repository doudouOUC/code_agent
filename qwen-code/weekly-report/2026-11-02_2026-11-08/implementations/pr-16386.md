## 解决了什么问题

SSH 注册完成/parked 结算仍占租户锁且 owner 更新按 registration 非点查；冻结 commit 的主 Session worktree 准备也独占目录，阻塞可共存的 Runtime/上传。

## 最终实现方案

最终 diff 让 SSH complete/completeParked/releaseParked 只按原 operation claim、alias 与 physical owner 结算；publish 用锁定 alias 的 physical_key 加 registrationId 点更新 owner，必须恰一行，否则回滚。新增 StorageOwnerMembership：仅 LOCAL 且 holder hash、maintenance id/generation 与原 SESSION_WORKTREE operation/target/physical 精确匹配的 preparation 可共存；判定保留 BLOCKED/过期 identity，不在 owner 后反向锁 operation。Runtime 准入/release、上传、已停止清理/operator recovery 共用该检查；preparation 可有成员，其他 child/checkout cleanup/物理维护仍拒成员，未知 Git 仍保原 holder。已在 main 落地，但不扩大 SSH/CSI 或任意 maintenance 放行。
