# PR #16225 最终实现：Session 命令缩小锁范围并保幂等

> PR: [perf(managed-agent): take session commands off the tenant lock](https://github.com/QwenLM/qwen-code/pull/16225)
> 状态：merged；最终 head `086d8713ad40`，merge `51bf9c366617`，对照 main `45cde869985a`。
> 规模：+327 / -26，8 个文件

## 解决了什么问题

模型、审批、扩展管理、压缩及重命名后续阶段等 Session 级操作争同一租户锁；缺失 receipt 上的锁定读还会把不相干 Session 放进共享索引 gap，造成插入死锁。

## 最终实现方案

目标入口改用原 Session 锁与存储 fence，不改 actor、状态、revision、claim 或 operation 检查。beginSessionMutation 的 replay probe 改普通读，唯一 receipt key 仲裁并发插入；DuplicateKey 后当前锁定读核 requestDigest/Session，不同内容返回 idempotency_conflict。rename 的初次 operation 范围准入仍保 tenant guard；settle/claim/retry 等指定阶段去锁，不能写成重命名全过程无租户锁。最新 main 的审批并发细节再由 #16296 修正。

2026-11-06 最新 main 复核：#16329 为指定 Session 命令使用 FOR SHARE 存储准入；本项保留的 rename 首次 guard 等例外不因此消失。
