## 解决了什么问题

现有静态 Skills/扩展发布依赖 daemon 准备，缺少 Managed-only 上传/表单与所选 Runtime 快照；Workspace settings 又不能当个人 OAuth grant。

## 当前实现方案

当前 open diff 复用原 archive/pin/settings/config_install：控制面先 operator+部署策略校验，将有界 Skill/扩展/MCP 输入交认证 Hosted 纯准备/预览/inspection，规范化 snapshot archive 后复用原幂等发布。预览不创建 revision、不启动 Runtime/模型/MCP/安装脚本；准备有并发/磁盘/期限/产物上限。Runtime Skill discovery/snapshot 核原 owner/generation、根路径和复制前后身份/摘要，source_changed 拒绝，不回退宿主目录。显式 idle apply 保 expectedConfigRevision，其他 Session 仍固定原版本。MCP 表单秘密经声明 settings 占位符保存，不在 archive/浏览器 storage 回读；个人 HTTP OAuth 独立加两张加密 grant/attempt 表，PKCE/state/actor/browser nonce/generation 与 CAS refresh/revoke，Runtime 每请求取得限定 token，不搬 daemon token。默认关闭且需管理员证明隔离 profile/provider 与持久 execution actor，child/automation 等不隐式继承。SDK/OpenAPI/管理 UI 同步，但候选 schema/能力不能视为 main。
