## 解决了什么问题

Hosted 普通工具不能持久提问，Java/WebShell 仅接受 permission；若只在前端加表单，断连/重启或回答后结果未提交会丢失问题或重复推进模型。

## 最终实现方案

在有 approval 的普通 files/1、/2、/3、shell/1 根 Session（含 public Plan）声明 ask_user_question，必须独占 batch；MCP/Hook、foreground-only、Resident/CSI、child/memberPlan 均不广告。先持久 input/definition/native continuation，再提交 question Action 的 options v4/hosted-user-question/1，requiresHumanDecision=true，yolo/auto 也不自动答。1–4 个必答问题、每题 2–4 选项与自定义文本用原顺序 qN/qNoN ID，单选为一个 option 或文本、多选可兼容文本；输入总 UTF-8 16 KiB、canonical answers 32 KiB，文字上限另校验。Java 与 TS 统一按原题/选项序规范化答案，decision v2 含 revision/policy，重复等价重放原结果、冲突拒绝；Action journal 核原 input/continuation/call/Runtime 和资源 digest，reader floor 升 2，不新增业务表。既有 ACTION_RESPONSE outbox、SDK resolveQuestion 与冷 attachment 完成原答复；恢复只续原 Action/原 call，过期取消不编造答案，问答本身不创建 Runtime tool execution。WebShell 用现有 radio/checkbox/textarea、稳定 SHA-256 幂等键和 in-flight guard；失败或未确认保当前草稿，页面重载重新查询 pending Action，不把答案存浏览器 storage，也不承诺草稿跨页面持久。

2026-11-08 最新 main 复核：#16484 后续扩至 definition/lineage 证明的一层 LOCAL shell child，并加入原 mount handback/reacquire 与逐 Action 草稿；MCP/Hook/Resident/CSI/memberPlan 及多层/扩展 agent 不推广。本文原根 Session 范围是本项最终 diff，不是最新问答完整范围。
