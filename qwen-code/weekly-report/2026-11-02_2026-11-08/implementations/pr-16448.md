# PR #16448 最终实现：Managed automation 默认启用且保显式关闭

## 解决了什么问题

已完成接线的 scheduler/gated automation 仍因 Java 属性和 shipped YAML 默认 false 而保持静默，省略配置的部署无法按既有定义扫描。

## 最终实现方案

ManagedAgentProperties.Automation.enabled 与 application.yml 的 QWEN_MANAGED_AGENT_AUTOMATION_ENABLED fallback 同改 true；显式环境变量或 qwen.managed-agent.automation.enabled=false 仍关闭。scan 10s、lease 60s、late tolerance 5m、lookback 24h、max slots 1000、concurrency/scanner threads 各 4 保原值。此项只改宿主总开关，不新建 schedule/开启已禁用定义，不绕过 Session mode、原 receipt/claim/revision/leader/gate/权限与 Runtime 能力；不开全部 Channel/Goal/Live 设计。测试隔离显式关闭自动 scanner，保手动 fake scanner 和 off 时忽略无效 tunables 的原规则。

## 关键代码路径

- `packages/managed-agent-server/server/src/main/java/com/alibaba/qwen/code/managedagent/config/ManagedAgentProperties.java`：Automation enabled 默认值及原配置验证。
- `packages/managed-agent-server/server/src/main/resources/application.yml`：环境 fallback true。

本次独立核对 diff、完整 changed files、相关测试与最新 main；未运行 Java/Maven、Node、CI、MySQL、Hosted、浏览器、真实模型或平台测试。命令需匹配源码的 JDK 21/SDK/依赖与构建产物，Java 使用隔离 Maven 仓库。从 `packages/managed-agent-server` 聚焦 `mvn -Dtest=ManagedAgentPropertiesTest,AutomationScannerTest test checkstyle:check`。源码同时核直接对象/YAML 缺省 true、环境/属性 false、原 tunables 以及关闭时验证规则。真实 scheduler/gate/多实例、故障和部署门禁另验，本次不执行。
