## 解决了什么问题

Hosted 刻意关闭环境本地记忆，现有 Mem0 配置不能作为 tenant/actor 鉴权；跨 Session 个人记忆需要持久归属和不明写入保护。

## 当前实现方案

当前 open diff 为每个认证 tenant+actor 幂等创建 Store，Session 显式 memory_store_id 绑定且不可变，省略关闭；SQL 保存 opaque namespace、条目归属/墓碑和 owner_only，Holo 只存正文。私有 Session 的列表/历史/SSE/产物/修改/转发及子上下文执行 owner 检查，子 Session 不自动继承 Store，Workspace 文件仍共享。writer/generation 与 MEMORY receipt 在短事务受理，外部 HTTP 在事务外，结果持久后回放；丢失写结果保 unknown 不盲重试。真实用户输入做最多 512 字查询、5 条/4000 字上下文、5 秒 provider 截止的召回，作为不可信参考，后台不触发。四个 context_* 工具显式写/删、infer=false，删除核原 scope/完整内容并保存墓碑；纯记忆批次 runtime:null。配置默认 false、session-memory/1 capability 与 Session Store 均需支持。候选修改 V1，不提供旧库升级。
