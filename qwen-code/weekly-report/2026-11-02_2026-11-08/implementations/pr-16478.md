# PR #16478 最终实现：合格工具准入以 Session root 代 tenant placement

> PR: [perf(managed-agent): take tool execution admission off tenant placement](https://github.com/QwenLM/qwen-code/pull/16478)

> 规模：+478 / -20，9 个文件

## 解决了什么问题

普通 session-class 工具 admit 仍因 Harness drain fence 先争租户 placement，导致相互独立的 Session 串行。只删除锁会读到过旧 RR snapshot 或与 drain 交错。

## 最终实现方案

ExecutionAdmissionPlacement.free 在独立连接预判：已有公共 Session root、普通 session isolation、无 Resident/CSI/shared Runtime/lifecycle authority，storage 为 absent 或 LOCAL 才可省 placement。准入事务第一条锁语句锁原 root，之前不建立普通读 snapshot；requestHarnessDrain 仍 placement-first，再锁该 root，从而与 Harness fence 读取排序。缺 root、其他存储/profile 走原 placement。completeStoppedSessionRelease 改 binding-before-storage，与准入原 binding/owner 锁序一致；execution 唯一幂等、原 generation/lease 与 storage admission 不取消。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/ExecutionAdmissionPlacement.java`：free 预判、lockEntry 与 lockDrainRoot。
