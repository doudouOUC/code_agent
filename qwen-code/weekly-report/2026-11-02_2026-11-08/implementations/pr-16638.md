## 解决了什么问题

自助安装的输入包不能代替所选 Runtime 的真实 Skill；跨 owner、路径变化或复制中变更会导入错误内容。

## 当前实现方案

当前 open diff 从 #16500 拆出 Runtime Skill discovery/snapshot/import，base 为 codex/managed-skills-mcp-self-service。控制面要求原 Session 扩展管理与 Workspace execution 权限、支持的 shell/MCP profile、开关和 Harness capability；每次响应重核 sessionId 与 bindingId/generation。Runtime 只在授权原根的 .qwen/skills、.agents/skills 扫描，拒绝符号链接/特殊文件/越界，过滤私密文件，以路径/模式/内容摘要和复制前后身份检查拒绝 source_changed。快照单独冻结 archive digest，分块下载逐块核 owner/offset/总量并复算 SHA-256，控制面最多 4 并发下载和 10 分钟截止。预览复用 #16500 纯包检查，显式导入才按原幂等 key 发布；发布不自动 apply，不回退 daemon/home 或另一 Workspace。

## 关键代码路径

- `packages/managed-agent-server/control-plane/src/main/java/com/alibaba/qwen/code/managedagent/extensions/ManagedRuntimeSkillImportService.java`：Session/owner 复核、分块下载与原发布复用。
- `packages/cli/src/serve/managed-runtime-skill-source.ts`：可信源扫描、前后摘要、临时快照及容量/期限。
- `packages/web-shell/client/components/managed/ManagedRuntimeSkillsImporter.tsx`：候选、预览与显式导入。
