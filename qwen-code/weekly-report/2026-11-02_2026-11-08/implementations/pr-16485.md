## 解决了什么问题

存储别名摘要实现重复，多个后端手写 SHA-256 易在后续维护时改变持久 key 或错误引入字符编码差异。

## 最终实现方案

将存储 alias key 委托同一 ManagedSchemaKeys 编码，固定 UTF-8、长度前缀、null/顺序和原 canonical bytes；以 DigestUtils.sha256Hex/getSha256Digest 替换等价 JDK 包装。增量流式摘要、固定输入顺序和 constant-time 比较不改。LOCAL 直接声明 commons-codec，其他模块复用已声明依赖；不迁移持久身份、不改 catalog/schema 或权限。

## 关键代码路径

- `packages/managed-agent-server/contracts/src/main/java/com/alibaba/qwen/code/runtimebroker/schema/ManagedSchemaKeys.java`：长度前缀身份摘要。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcRuntimeBindingRepository.java`：storageAliasKey 委托。
- `packages/managed-agent-server/runtime-local/pom.xml`：直接摘要依赖。
