# PR #16101 最终实现：将 Hosted 故障探针接回真实执行拥有者

> PR: [test(managed-agent): Reconnect Hosted fault probes to execution owners](https://github.com/QwenLM/qwen-code/pull/16101)
> 状态：merged；最终 head `dddf40c6fa4f`，merge `cd1e5feda5d9`，对照 main `624d10532ab8`。
> 规模：+170 / -15，3 个文件

## 解决了什么问题

Broker 提取 dispatcher/cancellation 后，测试仍替换 facade 的旧 transport 字段，无法观察真实 execute/cancel，也无法在指定故障点阻止结果结算，故障测试可能失去作用。

## 最终实现方案

HostedCancellationProbe 从 facade 取得 executionDispatcher 和 executionCancellation，读取真实 dispatcher transport，并把计数代理同时装入两个拥有者；close 同时恢复原 transport，后续执行不再被旧 probe 计数。计数仍区分启动、完成与取消请求，收到 cancel_requested 不提前增加完成数。

HostedWorkspaceToolTurnIT 将指定 Harness Session 的 execute CompletionStage 与外部 gate 组合，门未释放即不向 Broker 交付结果；status 失答路径通过该 helper 接到 dispatcher，而不是无效替换 facade。新增回归测试在真实 Broker 服务/内存 repository、mock transport 下验证 EXECUTING→CANCEL_REQUESTED→SETTLED、恢复原 transport 和延迟结算；不修改生产取消算法。

## 关键代码路径

- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/HostedCancellationProbe.java`：同时观察/恢复 execute 与 cancel 的 transport。
- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/HostedWorkspaceToolTurnIT.java`：向真实 dispatcher 注入指定 Session 的结果门。
- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/HostedExecutionTransportProbeTest.java`：探针计数、恢复和结算时序断言。

## 验证方式

本次读取三文件最终 diff 并核 main，没有运行 Java/Hosted 或故障门禁。先在 `packages/managed-agent-server` 聚焦 `mvn -Dtest=HostedExecutionTransportProbeTest test checkstyle:check`；随后按已有 Hosted profile 执行真实取消/失答场景。mock transport 的状态断言不证明物理进程停止、模型链路或 CSI 平台资格。
