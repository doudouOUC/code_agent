# PR #16221 最终实现：Harness 独立只读准入检查移出租户锁

> PR: [perf(managed-agent): take harness admission checks off the tenant lock](https://github.com/QwenLM/qwen-code/pull/16221)

> 规模：+216 / -7，4 个文件

## 解决了什么问题

每次工具派发前的独立 Harness admission、Hook、recovery 和 cleanup 检查先等待租户 placement guard，即使检查只读或该 scope 不受 Harness 管理，也被同租户写入串行化。

## 最终实现方案

七个独立入口只去掉 lockPlacementDomain，仍在原事务读取 ma_session/ma_session_head 的 phase、operation、claim generation/lease 和恢复协议版本；connection-taking 内部路径继续服从调用方事务。后续 authorizeDispatch 的 READY/generation 和 resident 重验不省略。最新 main 的 #16268 又为携 lifecycle authority 的检查对 claim mirror 使用当前共享锁（H2 用 FOR UPDATE），让 claim 清除/变更等待已准入事务；不能继续把所有 authority 检查概括为无锁快照。
