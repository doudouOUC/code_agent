# PR #16312 最终实现：存储预检显式只读并跨快照复核

## 解决了什么问题

外层 Workspace readScope 虽已分离，内层 verifiedRoot/fileRoot、physical owner key 和 worktree storageIdentity 仍根据事务存在隐式加 FOR UPDATE，读请求继续排在其他共享读者后；单快照 source 也可能漏掉读中撤权或存储换代。

## 最终实现方案

新增 verifiedRootForRead、fileRootForRead、requireOpenForRead 和显式 lock=false 的 LOCAL owner/key 读取，仍验证 alias/owner READY、原 marker、device/inode、history 和 cwd。Session 文件读改用只读 root；SessionWorktree source 用两个独立 REPEATABLE READ 快照复核 ResolvedBinding/root/storageIdentity，变化报 worktree_source_changed。真正 admit 仍显式 lock=true 并复核原身份。marker 读/发布提取为包内 WorkspaceStorageMarkers，保 4096-byte 上限、NOFOLLOW、原子发布与 probe 瞬态错误分类，不修改持久 marker 格式。
