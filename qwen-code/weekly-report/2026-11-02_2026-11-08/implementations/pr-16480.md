## 解决了什么问题

claim/renew/release operation 只改变操作租约，却仍取整组 CSI tenant guard，增加普通绑定的争用。

## 最终实现方案

lease-only claim/renew/release 通过 lockBindingControl(..., true) 复用 lockExecutionControl：普通已有 root 只核原 Session pin/marker，随后仍锁原 binding、校验 operation owner/generation/期限。compareAndSet 会后续拿 placement，因此明确使用 false 保 guard-first，不能 root 后补 placement。fallback 只有 profile binding 才拿 retention root；Resident claim 原 placement 和缺 root/CSI 路径保留。没有放松 binding 状态迁移或停止证据。

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcRuntimeBindingRepository.java`：lease true 与 CAS false 分流。
