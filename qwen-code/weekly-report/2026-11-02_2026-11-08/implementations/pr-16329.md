# PR #16329 最终实现：Session 命令共享存储准入 fence

> PR: [perf(managed-agent): share the storage fence in session command admissions](https://github.com/QwenLM/qwen-code/pull/16329)

> 规模：+177 / -6，7 个文件

## 解决了什么问题

模型/审批、MCP/extension、压缩、任务取消和 Action 响应虽不写存储行，仍独占 alias/owner 锁，造成共享存储上不同 Session 排队。

## 最终实现方案

指定入口改用 requireOpenForAdmission/requireSessionOpenForAdmission，MySQL FOR SHARE、H2 回退 FOR UPDATE；Session、权限、revision、空闲/claim 与请求幂等仍保留。事务不在共享读取后升级写这些行，fence 写者仍等待所有已准入命令。此项不把 publication writer 一并改共享：该 lane 当时可能同事务承载 lifecycle authority，后续 #16370 才将符合条件的普通 journal/publication 物理检查改为不锁；不能倒算为本项能力。
