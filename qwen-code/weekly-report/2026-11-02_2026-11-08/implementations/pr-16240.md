## 解决了什么问题

HostedWorkspaceConcurrencyIT 在第二 Runtime 加入后继续使用单成员旧快照，无法正确断言共享 owner 在各次释放中的 member_count。

## 最终实现方案

只修改真实并发测试：第二 Runtime 加入后重读 owner 并断言 member_count=2，释放一个后断言为 1，最后原成员释放后同时断言 holder_key=null 与 member_count=0。原未决身份不能随意释放的断言保留，不修改生产共享成员算法。
