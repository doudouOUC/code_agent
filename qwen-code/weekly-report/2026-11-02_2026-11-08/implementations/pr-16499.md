## 最终实现方案

最终 diff 已合入 codex/managed-session-diagnostics-20261106，而非 main。以 assistant UUID+functionCall ordinal+tenant/Session 生成 invocation 身份，typed activity evidence 关联原 message/intent/result/receipt；SQL 原 journal 事务增量投影 tools/files/skills 与有界累计，重放替换贡献，不以名字/provider ID 去重。区分请求、准入、执行和交付，Skill load 不证明后续模型消费，原生显式文件不推断 Shell/MCP 隐式 I/O。被动 activity-stats/activity 查询保原授权/no-store、分页和覆盖限制，UI 可惰性展开已持久谱系，父子用量不混加，也不开放多层执行。storage floor 4 与 CSI /3 是该候选链协议，不是当前 main；精确执行方耗时/行数仍由 open #16498 后续提供。
