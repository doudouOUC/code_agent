# PR #16223 最终实现：Turn 受理按 Session 与存储 fence 排序

> PR: [perf(managed-agent): take turn admission off the tenant lock](https://github.com/QwenLM/qwen-code/pull/16223)

> 规模：+272 / -24，8 个文件

## 解决了什么问题

每个新 Turn 为串行化迁移而先等租户锁，导致不相干 Session 互相阻塞。若直接删锁，迁移事务可能在旧 REPEATABLE READ 快照中漏掉刚提交的 Turn，错误认定目录空闲。

## 最终实现方案

insertTurnCommand 先点锁 Session，再核原权限/状态与 storage alias/directory fence，不再拿 tenant guard。迁移 prepare 在锁住源 alias 后，以独立 autocommit/read-only 连接读取已提交的 Turn、operation、receipt、writer、action 和 worktree 等 idle 证据；晚到受理等待 fence 后拒绝，先提交受理必须被 idle 检查看到。最新 main 的 #16268 将只读存储准入进一步改为 FOR SHARE（H2 用 FOR UPDATE），保持 Session-first 和维护互斥。

2026-11-06 最新 main 复核：#16327 将迁移的新连接检查扩为完整 Session/genesis/definition profile，仍先锁源 alias，不能只依外层 RR 的 profile 视图。
