# PR #16335 最终实现：普通工具发布与读租约移出 publication 租户锁

> PR: [perf(managed-agent): take ordinary tool publication and read leases off the tenant lock](https://github.com/QwenLM/qwen-code/pull/16335)
> 状态：merged；最终 head `697dbccb8e3a`，merge `f3488b47fa4e`，对照 main `7d99e7d26ee4`。
> 规模：+772 / -172，16 个文件

## 解决了什么问题

普通 reserve/producer/admission、工具结果投影和读租约都争 tenant publication CAS 行，单 Session 会拖住其他 Session；去锁若不保 root/head 顺序则会与回收形成环。

## 最终实现方案

普通发布按 Session root→head→publication/operation 行排序，不再取 publication tenant guard；CSI original 与 lifecycle-authority receipt 仍保专用锁。读 lease 建立、资源 quarantine 和普通投影 claim/complete 按原 root/head 串行；续租只锁原 Session root 并核 retirement generation/expiry，不额外锁 head，private Session 仍拒绝。容量逻辑提取 ToolPublicationCapacityStore，过期 capture fence 的等待保持有界/命名错误。Session 字节上限仍精确；不同 Session 在聚合 sums 与 commit 间可同时准入，tenant bytes/active-captures 允许短暂自纠正超量，不再宣称强全局 quota。这里当时仍持 placement；后续 #16354 才按原 binding 条件去掉，#16370 再去普通 storage 行锁。

2026-11-07 最新 main 复核：#16410 又将普通 native snapshot 的 writer 检查复用无 placement/publication guard 分支，读 lease 保护仍在；CSI pin 保原特例。
