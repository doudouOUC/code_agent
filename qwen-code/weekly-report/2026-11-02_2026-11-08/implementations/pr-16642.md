## 当前实现方案

当前 open diff 是 #16475/#16499 活动方案的独立切片，base split/16475-b-model-stats，依赖 #16641 而非已在 main。以 tenant/Session、assistantMessageId+ordinal 的摘要固定 invocation，typed evidence 绑定原 intent/receipt/execution，admission/execution/delivery/capture 分维度；SQL 与 CSI 共享 deterministic reducer，以前后贡献替换避免重放重复计数。复用原资源与 DOMAIN 投影存 tools/files/skills/link/stats，不新增执行 authority/业务表。显式 read/write/edit 才给文件事实，Skill 指令加载不推断模型后续消费；查询只读授权、有界分页/coverage，投影恢复仅在 fenced writer 获取时按原 journal 链分批重建，非查询时重放。storage reader 3→4/CSI /3 与 WebShell activity/惰性授权子树仍为分支方案，不包含 #16498 的精确执行方耗时/增删行。
