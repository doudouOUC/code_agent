## 解决了什么问题

CSI/retention 多处复制 10 秒 statement helper，生命周期和注册校验反复新建 mapper，增加样板和配置漂移风险。

## 最终实现方案

JdbcRepositorySupport.statement 统一 prepareStatement+setQueryTimeout(10)，多个 CSI 和 retention 调用静态导入；历史 JournalRead 的按剩余预算只读 timeout 保独立，live 分支仍加 FOR UPDATE。ResidentWorkspaces 的静态 REGISTRATION_JSON 保重复键、未知字段和尾部 token 拒绝；connector/preflight 各复用私有 mapper，不改全局协议 mapper 或字节格式。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcRepositorySupport.java`：默认 statement helper。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcCsiActivationAdmission.java`：live/shared 与 historical timeout 分支。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/ResidentWorkspaces.java`：严格注册 mapper。
- `packages/managed-agent-server/adapters/src/main/java/com/alibaba/qwen/code/managedagent/harness/QwenHostedHarnessConnector.java`：生命周期 JSON mapper 复用。
