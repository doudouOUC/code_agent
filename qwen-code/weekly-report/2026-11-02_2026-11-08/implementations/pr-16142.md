# PR #16142 最终实现：删除 Store 分片重复默认委托

> PR: [refactor(managed-agent): trim store delegation boilerplate](https://github.com/QwenLM/qwen-code/pull/16142)
> 状态：merged；最终 head `68dc921210ad`，merge `0441faff2149`，对照 main `da42e5714ad0`。
> 规模：+136 / -226，17 个文件

## 解决了什么问题

Store 拆分后，facade 和内部协作者各保一层仅补 null/false 的重载，增加默认值漂移和静态锁审计歧义。ItemRow 又只中转到相同字段的 ItemRecord，没有额外行为。

## 最终实现方案

公开 facade 的签名、事务注解与默认语义保留，在入口显式传完整参数：actor/authority 等原默认 null，生命周期预算/Plan 等原默认 false，以及 listSessions 的 all/空标题、消息页 afterSequence=0。删除包内重复默认重载，不让内部 helper 再承担第二套公共兼容入口；不会因此给缺 actor 的旧入口新增权限。

AgentMessageProjection 的 RowMapper 直接构造 ItemRecord，移除 ItemRow、转换方法及未使用的全量读取 helper，选定页才取正文的流程保留。结果通过 List.copyOf 保持不可变，测试明确拒绝 clear。锁审计删除已消失成员/ItemRow 引用豁免；结构守卫改用 Spring 合成注解查询防 @Service/@Repository 漏检，SQL 检测先用 Locale.ROOT 大写，增加反例断言。本项合入时仍是完整静态锁审计，后续 #16139 已在 main 改为精确入口/事务/SQL 所有者清单与执行轨迹；不将后续替换归因于本项。
