## 解决了什么问题

Shell 的原始 stdout/stderr 在模型裁剪前缺少与原执行绑定的完整捕获。

## 最终实现方案

Shell 管道捕获进入分段 store；Session 在执行前持久记录 intent，结果 seal 后按 writer/activation 和调用身份接受 receipt，再推进 checkpoint。v3 工具路由关联结果 ACK。

## 关键代码路径

- `packages/core/src/managed-runtime/local-shell-result-session.ts`：原调用准备和 receipt 接受。
- `packages/cli/src/serve/managed-runtime-tool-executor.ts`：v3 调用与结果 ACK。
