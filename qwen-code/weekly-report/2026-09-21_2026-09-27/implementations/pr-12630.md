## 解决了什么问题

已有 v2 私有路由只约束 attestation。Tool execute、按原调用查询状态和 cancel 缺共享 wire schema，TS 与 Java 容易在字段、结果或 `UNKNOWN` 语义上漂移。

## 最终实现方案

最终合入 diff 扩展 typed route manifest，声明三个 POST 路径及 256 KiB 请求、1 MiB 结果边界，并增加共享 JSON schema/fixtures、TS 和 Java conformance 测试。调用引用以 session/prompt/call/args digest 固定原物理操作；status/cancel 查原调用，`unknown` 不代表未执行。cancel 也保留 `unknown` 响应，不把未见原执行误判为可重派。此 PR 是契约声明和测试，本身不包含 execute/status/cancel handler；后续主干已通过同一 manifest 放行并挂载 worker 工具路由，不能倒算为本 PR 的交付。

## 关键代码路径

- `packages/cli/src/serve/managed-runtime-attestation-contract.ts`：route manifest 和现有 raw gate 边界。
