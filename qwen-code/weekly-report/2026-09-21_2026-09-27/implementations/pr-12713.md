## 解决了什么问题

Hosted profile 的路由基础尚不能通过真实模型完成一个可持久结算的文本回合。

## 最终实现方案

Session 路由以持久 authority 准入输入和结算；模型配置注册零工具，工具调用或不支持的 continuation 失败关闭。已存在未结算输入或恢复不可用时拒绝普通 load，事件从提交事实投影。

最新主干 `e6e2c9efd1dd` 已在模型路径保留无工具输出的原 parts，并排除只含 thought 的历史答复；Session 路由又扩展了其他私有入口。以上是后续主干演进，不改变本 PR 当时的零工具准入范围，也不把其他入口算作本 PR 交付。

## 关键代码路径

- `packages/cli/src/serve/hosted-harness-session.ts`：Session load、prompt 与结算。
- `packages/cli/src/serve/hosted-harness-model.ts`：零工具模型调用。
