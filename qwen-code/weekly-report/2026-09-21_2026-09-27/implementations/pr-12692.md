## 解决了什么问题

Managed Agent 的持久公共身份、事件投影和 WebShell 入口尚未形成可连接的产品控制面。

## 最终实现方案

Spring 控制面通过 JDBC 保存 Session、Turn、幂等命令与投影；Harness 消费者按持久游标提交事件，公共 REST/WebShell DTO 和 SSE 由控制面提供。WebShell provider 选择本地或 Managed 链路，复用 Java Hosted client。

## 关键代码路径

- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/ManagedAgentStore.java`：公共状态、命令与事务投影。
- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/ManagedSessionStore.java`：journal 与 writer generation。
