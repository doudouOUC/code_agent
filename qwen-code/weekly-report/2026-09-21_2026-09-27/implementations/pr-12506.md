## 解决了什么问题

私有 attestation 契约已有路由和 fixtures，但缺少能以独立进程启动、接受一次性启动身份并对外证明自身身份的真实 CLI worker；只测 handler 不能证明 raw HTTP 入口可用。

## 最终实现方案

隐藏的 `qwen managed-runtime-worker` 命令从 stdin 读取一个封闭的 JSON boot 文档，限制 32 KiB 与 30 秒；校验后仅在 `127.0.0.1:0` 监听 v2 attestation，向 stdout 输出不含 token 的 ready 记录。启动参数/boot 错误在 ready 前失败；SIGINT/SIGTERM 关闭服务。该 worker 没有 tool execute/control 路由。

## 关键代码路径

- `packages/cli/src/cli.ts`：隐藏命令分发。
- `packages/cli/src/serve/managed-runtime-attestation-worker.ts`：boot 输入、loopback 监听、ready 与关闭生命周期。
- `packages/cli/src/serve/managed-runtime-attestation-worker.test.ts`：真实子进程/HTTP 入口与非法启动回归。

## 验证方式

本次核对合入 diff、最新主干代码与 worker 测试；未本地重跑 CLI suite。可运行 `npm test --workspace=@qwen-code/qwen-code -- src/serve/managed-runtime-attestation-worker.test.ts`、`npm run build --workspace=@qwen-code/qwen-code` 与 `npm run typecheck --workspace=@qwen-code/qwen-code`，覆盖真实子进程 attestation 和非法 boot。
