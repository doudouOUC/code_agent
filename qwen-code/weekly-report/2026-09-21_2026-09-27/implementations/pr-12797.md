## 解决了什么问题

用户不能从可见 Workspace 中选择并持久绑定 Session，前后端容易把默认目录当稳定身份。

## 最终实现方案

Java 提供带租户/actor scope cursor 的可见 Workspace discovery；WebShell 创建器根据 capability 展示选择并传递稳定 workspaceId，服务端仍在创建事务复核权限和绑定。

## 关键代码路径

- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/api/WorkspaceDiscoveryController.java`：公共与 WebShell discovery DTO。
- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/service/WorkspaceDiscoveryService.java`：权限过滤与 cursor。
