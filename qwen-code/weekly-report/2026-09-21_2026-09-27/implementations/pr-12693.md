## 解决了什么问题

Harness 重启后模型历史、checkpoint 与 writer 归属若仅存在内存，会造成恢复时丢失事实或重放副作用。

## 最终实现方案

Managed Session authority 用事务记录和持久资源表达输入、执行意图、checkpoint 与回执；writer/activation fence 决定提交权限。checkpoint schema 校验恢复闭集，HTTP store 和 scheduler 从已提交边界恢复，不把未提交 tail 当权威历史。

## 关键代码路径

- `packages/core/src/managed-runtime/managed-session-authority.ts`：提交事实与恢复授权。
- `packages/core/src/managed-runtime/managed-harness-checkpoint.ts`：checkpoint 结构与运行授权。
