# PR #12491 最终实现：将 review 信任状态移出工作区

> PR: [fix(review): Move trusted state outside workspaces](https://github.com/QwenLM/qwen-code/pull/12491)
> 状态：merged；按合入提交 `591c9f488bd6` 与最新 `main` 核对。
> 规模：+547 / -214，17 个文件

## 解决了什么问题

`qwen review` 的 worktree lease 和 base-tree trust 记录会授权清理和比较树复用。原路径位于可写工作区 `.qwen/review-leases`，reviewed code 可能影响这些宿主决策，也阻碍 Landlock 对可写工作区维持同等保护边界。

## 最终实现方案

以真实路径规范化的最外层仓库根目录计算 SHA-256 命名空间，把权威 lease 与 base-tree 记录放在 `$QWEN_HOME/review-state/<hash>`。嵌套 review worktree 与外层仓库共享命名空间，不同仓库隔离。旧工作区路径不再被读取为权限依据，也不再是内置 sandbox mask，但仍从 local diff 中排除。合入后的 lease service 为旧版 CLI 兼容仍写 advisory mirror；它不能反过来决定新 lease，混用新旧版本仍有协调风险。

## 关键代码路径

- `packages/cli/src/commands/review/lib/paths.ts`：规范化仓库根与全局信任状态路径。
- `packages/cli/src/commands/review/lib/base-tree-trust.ts`：迁移 base-tree 权威记录。
- `packages/cli/src/services/review-worktree-lease.ts`：新路径 lease、旧路径兼容镜像与回收。
- `packages/cli/src/config/config.ts`：移除旧路径自动 mask，保留显式策略。

## 验证方式

本次阅读合入 diff、当前主干代码及路径、trust、lease、sandbox 相关测试；未本地重跑 Node 测试。可在 qwen-code 工作区运行 `npm test --workspace=@qwen-code/qwen-code -- src/commands/review/lib/paths.test.ts src/services/review-worktree-lease.test.ts`、`npm run build` 与 `npm run lint`，并在 Linux 验证 sandbox 中工作区可写而全局状态不可写。

## 边界与风险

- 这不是 Landlock 实现；`QWEN_HOME` 迁移或仓库移动会改变状态命名空间。
- 旧镜像仍在工作区写入，但不作为新版 CLI 的权威输入。
