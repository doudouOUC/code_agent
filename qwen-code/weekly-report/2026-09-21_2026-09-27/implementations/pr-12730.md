## 解决了什么问题

Broker 虽可采用 Runtime，却不能证明 Runtime 已安装原 Session 的 Workspace/cwd context。

## 最终实现方案

managed-context 协议绑定 seed、lease、epoch 和 context digest；HTTP transport 在 acquire 时安装 context，校验原身份 receipt。JDBC binding/session 持久化相应上下文以便恢复时再次核验。

## 关键代码路径

- `packages/sdk-java/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/ManagedContextProtocol.java`：boot/context/receipt 严格契约。
- `packages/sdk-java/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/HttpRuntimeTransport.java`：安装与回执校验。
