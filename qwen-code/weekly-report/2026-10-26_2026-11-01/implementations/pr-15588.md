## 解决了什么问题

通用准入验收生成器沿用只读文件路由的请求形状：上传少了 query 参数/二进制类型，查询少了原 uploadId，对越权查询也期待了错误的资源错误码；测试可能在实际权限边界之前就被参数解析拒绝。

## 最终实现方案

SurfaceAdmissionAcceptanceTest 对 WORKSPACE_FILES_UPLOAD 填充 workspaceId/cwdRelative/path/expectedScopeRevision/uploadId，按 octet-stream 发请求；UPLOAD_QUERY 的 JSON body 仅带 uploadId。WORKSPACE_FILES family 的陌生 actor 探针按是否查询上传身份区分 workspace_upload_not_found 与 workspace_not_found，保持不泄露资源存在性。

仅修正测试 fixture，不修改生产路由、大小限制、创建权或上传对账。测试现在能抵达预期准入层，不代表该层或上传的真实环境验收已在本次运行通过。
