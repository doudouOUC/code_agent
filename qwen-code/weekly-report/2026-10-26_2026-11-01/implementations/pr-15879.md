## 解决了什么问题

中央 Hosted Harness 需要在云上执行 Workspace 文件和前台 Shell，但普通 sandbox 的创建失答、TTL 或目录存在不能证明原执行身份、持久数据连续性和安全关闭。直接重建或自动恢复暂停 VM 还会改变未知执行的物理对象。

## 当前实现方案

独立私有集成包使用 E2B SDK 2.61.0/Node >=22.19，模型、审批、SQL/journal 继续中央管理，云凭据仅由 adapter 持有。新增显式 external-workspace-files/tools，旧 external-scratch/workspace 准入不变。loopback operator 先注册原 provider/Volume ID/revision，再用原 key 原子发布 ACTIVE Workspace 与指定 actor 的 OWNER；公共 Session 必须选择该注册、cwd 为 .，拒无绑定或本地存储。SQL 核原 EXTERNAL owner/租户/revision，并以物理存储键限制同时执行，不把多个 Session 视作独立磁盘副本。

adapter 的 canonical 0700 目录/0600 SQLite、WAL/FULL 持久化原创建意图、请求摘要、随机 create key、route 和访问凭据，journal 绑定 provider/原 API key 摘要。同 key 只回原记录，SDK 创建 retries=0；创建失答而缺 traffic credentials 时只列原 metadata 并报 UNKNOWN，不二次创建、不用可能恢复暂停 VM 的 Sandbox.connect；启动先记一次性状态，失答不再次启动。新 sandbox 挂既有唯一 Volume，先 Volume-ID 写随机挑战、从 mount 读回，再写私有 boot 并启动匹配 Linux worker；不靠目录名证明挂载身份。

管理面和 wildcard worker HTTPS ingress 只代理白名单路由，核原 bearer/lease/epoch 后注入 E2B 私有 traffic token，不接受调用者指定上游 URL。观察核原 sandbox metadata、私有网络和 v3 attest，未确定不冒充 RUNNING。files 支持 Read/Write/Edit/WebFetch，tools 再加 Glob/前台 Shell，后者要求中央 HTTPS Tool Publication/Artifact；准备文件路径及确认/执行前复核 realpath 范围，拒替换输入。Hosted/Java SDK 把 fileRewindEnabled=false 持久 pin 并在创建/恢复重述，拒回滚、后台 Shell、PTY/Monitor、MCP/Hook/扩展、child Workspace、cwd/挂载转移和 Workspace 浏览。

关闭先释放原 worker Session、ACK 已结算结果，排空 channels/pending work 并发布原 files/tools retirement bytes；Broker 核摘要、boot/lease/storage revision 和零未结算计数。provider 先耐久保存原 binding/generation retirement key 与完整证明，再 kill 原 sandbox ID 并核 Cloud absence，Volume 保留；失答可仅确认原证明，RETIRING 沿同 key 重试停止，不重新依赖已消失 worker。仅 GONE、TTL、暂停或普通 release 均不证明 close，未知保留占用。

候选仍是模块拆分前的路径/基线，不是与当前 main 的 Maven 模块、公共快照删除或已关闭未合入的 #15696 整合版本。它依赖 E2B Volume API；不能仅替换 endpoint 就声称 AgentSandbox 兼容，也没有自动凭据轮换或未知创建自动修复保证。

## 关键代码路径

- `integrations/e2b-runtime-provider/src/provider.ts`：耐久 placement/原 key replay/证明先落库的退休状态。
- `integrations/e2b-runtime-provider/src/e2b.ts`：原 sandbox 连接、Volume 挑战、观察与物理停止。
- `integrations/e2b-runtime-provider/src/server.ts`：受保护管理面、原 scope worker ingress 和路由白名单。
- `packages/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/persistence/ExternalStorageRegistrationStore.java`：注册 owner 核验与 Workspace/OWNER 原子发布。
- `packages/managed-agent-server/src/main/java/com/alibaba/qwen/code/runtimebroker/provisioning/ExternalWorkspaceProvisioner.java`：files/tools boot、原 worker 与 provider 两阶段停止证明。
- `packages/cli/src/serve/managed-runtime-provider-worker.ts`：受控文件路径、原 Session 排空和严格退休。
- `packages/cli/src/serve/managed-external-publication.ts`：files/tools 原身份 stop proof。
