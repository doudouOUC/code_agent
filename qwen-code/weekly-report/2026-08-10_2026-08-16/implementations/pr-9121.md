> PR: [fix(telemetry): Address main agent tracing edge cases](https://github.com/QwenLM/qwen-code/pull/9121)

> 规模：+2592 / -129，18 个文件

## 解决了什么问题

#9107 把 interaction span 扩展为完整 main-agent invocation 后，评审继续暴露出若干边界漂移：wall-time budget abort 可能被 core generator 覆盖成普通 user cancellation；非流式 provider 或 idle stream 吞掉 abort 时可能把取消导出成 `ERROR`；TUI 延迟工具批次在 main prompt 与 legacy `?btw` 混跑时可能把 secondary 工具结果提交到 main continuation；headless JSON Schema verdict 会误套到 Cron、Notification、Teammate 或 runtime Goal drain 这类自动 invocation；Goal finalization 和 headless terminal failure 还会丢失真实有界错误消息。

## 当前实现方案

#9121 当前 open diff 是 #9107 的精确性 follow-up。headless `runNonInteractive` 在 budget abort signal 上提前 stamp `run_budget_exceeded`，并在 finally 移除 listener，防止后续 core finalizer 把同一 span 改写为泛化 cancellation。`LoggingContentGenerator` 为非流式和流式请求记录 abort 是否发生在 response/stream completion 前：provider 在 abort 后仍 resolve 时，不写成功 API/OpenAI log，LLM span 以 cancelled + `API call aborted` 收尾；abort 发生在完成之后则不改写成功；idle-timeout path 也按 abort/error/timeout 三种原因输出稳定状态。

TUI `useGeminiStream` 新增 deferred completed-tool batch drain。active model stream 未 settle 时，已完成工具先进入 pending batch；drain 时按 tool call id 还原 interaction owner，只选择仍 live 的 owner 继续 main continuation。secondary owner 的工具结果只进入 completion/Dual Output 侧效应，并把 secondary interaction 以 cancelled 收尾，避免 legacy `?btw` 工具结果进入 main prompt。提交 lease 在 continuation 与 drain 竞态下保持到真实 settle，取消中的 stream unwind 不会重新 arm lease。

Core `GeminiClient` 用 `WeakMap<interactionOwner, SendMessageType>` 记录 invocation 起点类型，只有 `UserQuery` 和 `Retry` owner 承担 session JSON Schema structured-output contract，并跨 tool continuation 继承；Cron、Notification、Teammate 与 Goal drain 的纯文本结果不再被误判为 `structured_output_missing`。Goal finalization 与 UserPromptSubmit/hook failure 的 bounded diagnostic message 分开，headless terminal failure 也保留真实 phase/error message。

## 关键代码路径

- `packages/cli/src/nonInteractiveCli.ts`：budget abort stamping、terminal failure message 与 listener cleanup。
- `packages/core/src/core/loggingContentGenerator/loggingContentGenerator.ts`：非流式/流式 provider abort completion classification、idle timeout status 与 API/OpenAI log suppression。
- `packages/cli/src/ui/hooks/useGeminiStream.ts`：deferred completed-tool batch、tool call owner selection、secondary interaction cancellation 与 submission lease retention。
- `packages/core/src/core/client.ts`：interaction owner 的 start type 记录、structured-output contract owner 判定，以及 Goal finalization failure message。
- `packages/core/src/telemetry/session-tracing.ts`：interaction attributes 的 JSON contract ownership 边界。
- `docs/design/telemetry-main-agent-spans-design.md`：#9107 design 的 edge-case 修订。

## 验证方式

PR 声明用定向单测覆盖 budget abort 优先级、non-stream swallowed abort、stream idle timeout cancellation、provider completion 后 abort 不改写成功、TUI main + legacy `?btw` mixed deferred tool batch、submission lease drain、JSON Schema user/retry owner 继承、automatic invocation 不误报 structured-output missing、Goal finalization 和 headless terminal failure 的有界错误消息。测试路径集中在 `nonInteractiveCli.test.ts`、`loggingContentGenerator.test.ts`、`useGeminiStream.test.tsx`、`client.test.ts` 与 `session-tracing.test.ts`；Windows/Linux 未本地验证。

## feature 文档处理

已在 telemetry/observability 的 main-agent invocation tracing 口径中登记为 #9107 后续 open diff。它不新增 telemetry surface 大方向，而是修正 #9107 已合入 contract 的取消、owner、structured-output 和 diagnostic message 边界。

## 边界与风险

- 当前未合入，不能作为 `main` 行为承诺。
- TUI 现在会等 active model streams settle 后再 drain completed tools，owner 选择和 queue drain 是主要风险点。
- workflow invocation、workflow dispatch tracing、跨平台验证和用户可见 UI 变化不在本 PR 内。
