> 规模：+2870 / -457，24 个文件

## 解决了什么问题

旧 `qwen-code.interaction` span 在 tool turn 的第一次模型响应后就结束，后续 tool execution 与 continuation LLM request 会变成不相关 root trace；成功 span 还使用 `OK` 而不是 GenAI 推荐的 unset status。OTel 后端因此难以把一次用户主 Agent invocation 还原成完整 trace。

## 当前实现方案

#9107 当前 draft open diff 将 `qwen-code.interaction` 对齐 OpenTelemetry GenAI Agent convention，并把它定义为一次完整 main-agent invocation。interaction span 新增 `invoke_agent` operation、`gen_ai.agent.name=qwen-code`、conversation/session identity、prompt-scoped ownership，以及成功/取消 unset、失败 `ERROR` + low-cardinality `error.type` 的状态语义。

interaction 生命周期跨越 tool approval、tool execution、model continuation、retry、Goal 与 ACP/headless/TUI 入口。并发 prompt 按 prompt id 隔离；stale owner 不能结束或修改 replacement span；shutdown/TTL cleanup 会关闭注册 span。tool span 继承真实 parent agent name，standalone tool 不写 agent name。启用 sensitive span attributes 时，interaction 只记录 trusted original user prompt 的 bounded `gen_ai.input.messages` 和最终用户可见 assistant response 的 bounded `gen_ai.output.messages`；expanded context、history、reasoning、tool preface/result、system instruction、image、失败 attempt 和中间 continuation 不写入。

## 关键代码路径

- `packages/core/src/telemetry/session-tracing.ts`：interaction owner registry、GenAI agent attributes、status/cleanup 语义。
- `packages/core/src/telemetry/detailed-span-attributes.ts`：bounded input/output message capture。
- `packages/core/src/core/client.ts`：main agent invocation lifecycle、tool continuation 与 structured output capture。
- `packages/cli/src/ui/hooks/useGeminiStream.ts`：TUI prompt/tool turn interaction owner。
- `packages/cli/src/nonInteractiveCli.ts`：headless interaction lifecycle 与 JSON output capture。
- `packages/cli/src/acp-integration/session/Session.ts`：ACP session interaction lifecycle。
- `docs/developers/development/telemetry.md` / `docs/design/*telemetry*`：GenAI/ARMS contract 更新。

## 边界与风险

- 当前未合入，不能作为 `main` 行为承诺。
- interaction duration 与 span count 会较旧版本变长，消费者需要适配 success/cancel unset status。
- workflow invocation/dispatch span、agent-level token aggregation、system instructions、tool definitions、provider request aggregation 和 hosted-agent identity 不在本 PR 内。
