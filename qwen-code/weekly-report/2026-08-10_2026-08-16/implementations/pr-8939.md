# PR #8939 最终实现：同会话刷新事务化

> PR: [fix(webui): Make same-session refresh transactional](https://github.com/QwenLM/qwen-code/pull/8939)
> 状态：merged，已合入 `main`。
> 规模：+2992 / -351，9 个文件

## 解决了什么问题

同一个 logical session 的 `load`、configured reload、`resume` 或显式 clientId rebind 仍走 destructive runner path。慢速、失败、partial、epoch mismatch 或 stale restore 会在 candidate settle 前 abort source SSE、detach source、清 prompt state 或替换 transcript，打断原本健康的当前会话并可能丢 live events。

## 最终实现方案

#8939 在支持 `client_identity` 的现代 daemon 上把 same-session refresh/rebind 也做成事务候选。candidate restore 运行时，当前 attachment、transcript、event stream、prompt state、metadata 与 controls 继续归 source 所有。candidate 必须通过 session/workspace owner、event epoch、cursor、replay completeness、bounded live tail、attachment identity 和 deadline 校验后，才能原子 commit replacement。

完整 load 会 staging replay 加连续 source tail，避免重复 replay arrays；`resume` 和 clientId-only rebind 保留 visible transcript，只替换 attachment identity 并使 stale pagination owner 失效。失败、超时、malformed、partial、superseded 或 stale candidate 只 retire 自己，不改变 source。与 cross-session switching 共用 restore coordinator，并依赖 #8933 的 exact replay shape identity。

TS daemon SDK 同步暴露 restore epoch 与 partial replay diagnostics，供 WebUI fail-closed 校验；旧 daemon 明确缺 `client_identity` 时继续保留 destructive full-load legacy 行为。

## 关键代码路径

- `packages/webui/src/daemon/session/DaemonSessionProvider.tsx`：same-session candidate staging、tail capture、commit/retire。
- `packages/webui/src/daemon/session/actions.ts`：create/prompt/shell/controlled target 与 refresh 的 owner priority。
- `packages/sdk-typescript/src/daemon/DaemonSessionClient.ts` / `types.ts`：restore epoch 与 partial replay diagnostics surface。
- `integration-tests/cli/qwen-serve-webui-same-session-refresh.test.ts`：held restore、structured 504、clientId rebind 真实 daemon 场景。

## 验证方式

PR 声明五个 pre-change baseline probe 已复现 destructive 行为，修复后 330 个 WebUI session tests、57 个 SDK session-client tests 与真实 daemon JSDOM integration 三个场景通过。验证重点是 source 在 candidate pending/failed 时保持可用，刷新 replay+tail 不丢不重，clientId rebind 后还能继续发送 prompt。

## feature 文档处理

已更新 WebUI/transport、session lifecycle 与 SDK 文档，明确 #8939 已合入，restore epoch / partial replay diagnostics 不再是 draft 观察。

## 边界与风险

- staging 期间内存短暂包含 source transcript、candidate replay 和最多 8 MiB source tail。
- 缺 cursor/epoch 的 source attachment 仍 fail closed 或走 legacy；跨 epoch/ring resync、live-journal repair、branch adoption 与 selective JSONL reading 仍是后续主题。
