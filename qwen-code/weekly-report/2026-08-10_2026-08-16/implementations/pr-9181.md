# PR #9181 当前实现观察：Conversations runtime boundary isolation

> PR: [feat(daemon): Isolate the Conversations runtime boundary](https://github.com/QwenLM/qwen-code/pull/9181)
> 状态：open，未合入 `main`。
> 规模：+8977 / -2192，66 个文件

## 解决了什么问题

#8890 已把 Conversations runtime foundation 从 Live 专属路径中抽出来，但 runtime 仍缺少跨 daemon 的单 owner 证明：两个支持 Live/Conversations 的 daemon 可能同时发布或使用同一 runtime；内部 `kind:"live"` workspace 也可能从普通 workspace selector、ACP/Voice/scratch target 或 Web Shell workspace picker 泄漏出去。shutdown 侧同样缺少“listener、app、host、discovery、bridge 和 child process 全部 drain 完成后才释放 ownership”的正向证明。

## 当前实现方案

#9181 当前 open diff 新增 `ConversationRuntimeOwnership`，把 Conversations runtime owner 记录落到稳定 real home 下的 `~/.qwen/conversations/runtime-owner.json`，记录 `{version:1,pid,instanceNonce}`。读写路径使用 lock file、same-directory temp+rename、目录 fsync、owner-only permission、O_NOFOLLOW、regular non-symlink/single-link 检查、4 KiB 文件大小上限和严格 schema 校验；发现 malformed/unsafe owner file 时进入 `ownership_compromised`，不会覆盖或删除外部记录。acquire 处理 active/same/dead owner、同 PID 不同 nonce、handoff grace 与 live discovery handoff；release 只删除 exact matching current record。

运行时生命周期改为由 `ServeAppLifecycle` 统一证明。Live/Conversations app 必须先 bind 实际 Node server，再开放 listener；boot admission 等 listener 与 host startup ready 后才放行。shutdown 时先 seal admission，等待 listener close、app/host drain、bridge/child work settle，再释放 ownership。`ConversationRuntimeActivityGate` 在 shutdown 后拒绝新的内部 runtime operation，并让已有 operation 参与 release 前的 drain 证明。

普通 workspace 路径默认看不到内部 Conversations runtime。新增 runtime visibility helper 后，ordinary resolver 会过滤 `provenance === "live-conversation"` 的 runtime；只有既有 Live catalog、owner-routed session 和少量兼容 route 使用专门 compatibility resolver。内部 runtime 查找失败、歧义或未持有 ownership 时 fail closed，不 fallback primary。Web Shell workspace picker、Voice target、scratch/session creation、ACP mount、extension/workspace management 等普通入口也同步排除内部 runtime。

- `packages/cli/src/serve/conversations/conversation-runtime-activity.ts`：shutdown activity gate 与 `daemon_draining` 拒绝。

- `packages/cli/src/serve/workspace-route-runtime.ts` / `workspace-runtime-visibility.ts`：ordinary runtime 隐藏内部 runtime，compatibility resolver 精确开放既有 Live path。
