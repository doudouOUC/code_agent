# PR #8990 最终实现：same-session refresh race gap closeout

> PR: [fix(webui): Close same-session refresh race gaps](https://github.com/QwenLM/qwen-code/pull/8990)
> 状态：merged，已合入 `main`。
> 规模：+396 / -86，6 个文件

## 解决了什么问题

#8939 合入后继续 review 发现五个确定性竞态缺口：默认 bounded-history refresh 可能拿不到稳定 event epoch 而无法通过完整性检查；event-driven timeout 可能遗留 provisional attachment 和 source-tail capture；turn terminal 先到、shell command 后结束时 queued refresh 可能永久不启动；create/branch 等 source-bound 操作期间的 controlled target 可能被丢弃；clientId rebind 已提交后又被初始 prop 覆盖，导致后续 resync recovery 用错 identity。

## 最终实现方案

#8990 是 #8939 的 post-merge hardening。daemon/bridge bounded replay load 现在稳定返回既有 event epoch 字段，让 WebUI candidate 校验有权威 epoch。Provider 在所有 terminal failure path 中释放 prepared candidate attachment，并停止 source-tail capture，避免 invisible attachment 或 capture leak。

刷新调度在 source-bound 操作 settle 后会恢复 controlled target；queued refresh 的 unblock 条件同时等待 observed turn 和 overlapping shell command 完成，避免单边 terminal 导致永久 queued。clientId rebind commit 后，Provider 保存 committed modern client identity，后续 ring-resync/recovery 不再被 initial prop 覆盖。

## 关键代码路径

- `packages/webui/src/daemon/session/DaemonSessionProvider.tsx`：candidate cleanup、source-tail capture release、refresh queue unblock、committed client identity。
- `packages/acp-bridge/src/bridge.ts` / `bridge.test.ts`：bounded load 返回 event epoch。
- `packages/acp-bridge/src/bridgeTypes.ts`：restore response diagnostics。
- `integration-tests/cli/qwen-serve-webui-same-session-refresh.test.ts`：held-response replay plus live-tail path。

## 验证方式

PR 声明 focused/full unit suites 与真实 daemon integration 通过。验证重点是 bounded load 可 commit、event-driven deadline 后 candidate/capture 释放、turn+shell 都结束后 queued refresh 启动、session creation 期间 controlled target 不丢、clientId rebind 被后续 recovery 使用。
