# PR #8954 最终实现：session list cancellation propagation

> PR: [feat(serve): Propagate session list cancellation](https://github.com/QwenLM/qwen-code/pull/8954)
> 状态：merged，已合入 `main`。
> 规模：+1381 / -126，16 个文件

## 解决了什么问题

#8892 引入 persisted session catalog single-flight cache 后，多个 REST/ACP/LiveTask 调用方可能共享一次昂贵的 JSONL/worktree sidecar 扫描。旧路径在请求断开后不取消扫描，会浪费 daemon 资源；但如果把 caller `AbortSignal` 直接连到 shared loader，一个 waiter 断开又会取消所有消费者，破坏共享缓存语义。

## 最终实现方案

#8954 把 `PersistedSessionListCache` 改为 waiter-aware cancellation。每个调用方注册独立 waiter；单个 waiter abort 时只拒绝自己的 promise，不影响共享 physical load。只有最后一个 cancellable waiter 取消时，cache 才 abort loader、detach 当前 slot，并允许下一次请求立即启动 fresh scan；旧 load 的晚到 rejection/settlement 不会清掉 replacement slot。

取消传播从 route/ACP transport 一直下沉到实际 I/O：organized/metadata list、numeric pagination、trusted secondary persisted preflight、JSONL `readLines`、runtime status read、worktree sidecar read、migrated-session project membership read、cooperative directory scan 都接收 `AbortSignal` 并在 await 后检查。目录扫描每 128 个 entry yield/abort 一次，避免大 catalog 下长时间不响应取消。

## 关键代码路径

- `packages/cli/src/serve/server/persisted-session-list-cache.ts`：waiter bookkeeping、last-waiter abort、detached load identity。
- `packages/cli/src/serve/server/session-list.ts`：list options 传递 signal，organized/metadata/pagination cancellation。
- `packages/cli/src/serve/routes/session.ts` / `acp-http/dispatch.ts`：REST disconnect 与 ACP connection destroy 传入 caller signal。
- `packages/core/src/services/sessionService.ts` / `worktreeSessionService.ts`：目录扫描、project membership、runtime sidecar cancellation。
- `packages/core/src/utils/jsonl-utils.ts` / `runtimeStatus.ts`：底层 file/stream read signal-aware。

## 验证方式

PR 声明覆盖 cache 单元测试、REST/ACP transport tests、server regression、SessionService/worktree/jsonl/runtimeStatus tests。关键验证包括两个相同 organized request 断开一个仍共用 scan；全部 waiter 断开后 physical scan abort；下一请求不等 TTL 直接新扫；取消期间不返回 partial data、HTTP 500、ACP error frame 或 cancellation error log。

## 边界与风险

- 取消是 cooperative，不试图中断已经进入内核的同步/底层 stat 调用。
- 不覆盖 CLI resume/picker 或 WebShell GET 之外的所有 catalog 调用方；新增调用方需要显式传 signal。
