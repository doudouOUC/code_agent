# PR #9039 最终实现：privacy-safe tool-result boundary diagnostics

> PR: [feat(core): Add privacy-safe tool-result boundary diagnostics](https://github.com/QwenLM/qwen-code/pull/9039)
> 状态：merged（2026-08-17）。
> 规模：+3907 / -162，39 个文件

## 解决了什么问题

大型 tool result 会先后经过 producer preview、model-facing finalizer、chat recording、ACP projection、Headless projection 和 transport writer。现有日志能看到某处出现大帧，却不能在不泄露正文、路径、prompt 或稳定 ID 的前提下定位第一个改变表示的边界。#9012 与 #8450 把不同 transport 的文本结果变成有界预览后，这个诊断缺口更明显。

## 最终实现方案

#9039 最终实现新增 opt-in 的 tool-result boundary diagnostics。只有启用 file debug logging 时才观察 eligible 边界，并用 process-local 随机 key 计算 HMAC-SHA-256；事件只记录 byte/character size、HMAC、是否 mutated、closed artifact state/kind summary 和 writer frame size，不记录 result text、prompt、session/prompt/tool-call raw id、tool name、artifact path/title/url 或文件路径。

Core 侧在 producer、tool response finalizer、chat recording、Agent runtime 和 speculation 边界调用 shared observer。CLI 侧新增弱关联层，把 ACP/Headless projection 的 input/output 与后续 writer frame 关联起来；ACP live/replay/subagent、Headless JSON/stream-json、persistent SDK transport、Dual Output 和 subagent progress 都只携带安全 artifact summary，不改变 wire schema。诊断事件按 50 eligible events/minute 限流，并吞掉诊断自身异常，确保 debug-on/off 时业务输出字节一致。

## 关键代码路径

- `packages/core/src/utils/tool-result-boundary-diagnostics.ts`：process-local HMAC、eligible 判断、artifact summary 与 event emission。
- `packages/core/src/core/coreToolScheduler.ts` / `tool-response-finalizer.ts` / `chatRecordingService.ts`：producer、finalizer 和 recording 边界观察点。
- `packages/core/src/agents/runtime/agent-core.ts` / `followup/speculation.ts`：Agent/subagent/speculation 结果边界。
- `packages/cli/src/utils/tool-result-boundary-diagnostics.ts`：ACP/Headless projection 与 writer 弱关联。
- `packages/cli/src/acp-integration/session/emitters/tool-call-emitter.ts` / `history-replay-page.ts`：ACP live/replay 投影诊断。
- `packages/cli/src/nonInteractive/io/BaseJsonOutputAdapter.ts`：Headless JSON/stream-json writer 诊断。

## 验证方式

PR 声明使用 deterministic 499,999-byte fixture 覆盖 Headless JSON、stream-json 与 ACP，确认 writer byte size 与捕获 JSON/NDJSON frame 精确一致、HMAC mismatch 能定位首个 mutating boundary、debug-on/off 业务输出完全一致，且所有新增事件不包含正文、prompt、raw id、tool name 或 artifact path。测试覆盖 core/CLI focused suites；嵌套 subagent E2E 未跑，相关路径由跨包单测和静态消费者追踪覆盖。

## feature 文档处理

已在 tool-response-budget 与 telemetry/observability 口径中登记为 merged diagnostics：它是调试诊断层，不改变 #7323 model-facing finalizer、#8450 ACP projection 或 #9012 Headless projection 的语义。

## 边界与风险

- 只在 file debug logging 启用时运行；成本由 lazy enablement、速率限制和 failure isolation 控制。
- 不提供通用 frame/backpressure 限制，不改变 artifact 生命周期、wire schema 或 SDK 类型。
