# PR #8933 当前实现观察：restore request shape-aware coalescing

> PR: [fix(serve): Keep restore request shapes distinct](https://github.com/QwenLM/qwen-code/pull/8933)
> 状态：open，未合入 `main`。
> 规模：+902 / -26，7 个文件

## 解决了什么问题

restore coalescing 过去主要按 session/workspace target 合并，无法区分 replay 语义。一个 pending `load` 可能满足后来 `resume`，`recent(100)` 可能共享 `recent(500)` 或 `all` 的 raw result，导致 WebUI 或 bridge 得到错误 replay。

## 当前实现方案

#8933 的 open diff 在 WebUI 和 ACP bridge 两层都把 restore identity 改为 shape-aware：target 外还包含 `resume/none`、`load/all` 或 `load/recent(N)`。相同 shape 可以 coalesce；非等价请求需要串行、冲突或被新 lifecycle cancel fence 隔离。

WebUI 在 intent admission 时捕获 replay page，commit 前确认 raw result 仍属于当前 lifecycle。ACP bridge 在 cold restore coalescing 中纳入 effective page，并在 restore admission 前校验 response page size；对 streamed load/resume 无意义的 page 值不会污染 identity。普通 same-shape timeout retry 仍可 adopt late result，但被 lifecycle cancellation supersede 的 result 不能 commit。

## 关键代码路径

- `packages/webui/src/daemon/session/DaemonSessionProvider.tsx` 与 tests：shape-aware request identity、superseded raw result fence。
- `packages/acp-bridge/src/bridge.ts` / `bridgeTypes.ts`：restore request shape、effective page validation 与 coalescing。
- `docs/design/2026-08-10-transactional-webui-session-switching.md`：restore shape 与 transactional switching 关系。
- real-daemon integration tests：same target 不同 replay shape 的回归。

PR 声明 237 个 WebUI tests、553 个 ACP bridge tests、3 个 real-daemon switching scenarios、Prettier/focused ESLint/build/typecheck。由于 PR 仍 open，本仓文档只记录当前 diff 观察。
