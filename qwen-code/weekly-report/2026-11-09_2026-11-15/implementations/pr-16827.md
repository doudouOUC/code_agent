# PR #16827 最终实现：复用已读事实减少重复查询

> PR: [perf(managed-agent): remove redundant read-path queries](https://github.com/QwenLM/qwen-code/pull/16827)
> 状态：merged；最终 head `b4d615b9a02f`，merge `aa51bbdf779f` 已在 main；对照 main `74b8cde46612`。
> 规模：+11 / -11，3 个文件

## 解决了什么问题

同一次控制流中重复读取 Git tree diff、自动化 occurrence 或 Runtime binding，浪费 IO/数据库往返，也使错误原因与状态可能来自两次不同读取。

## 最终实现方案

`ChildWorktreeGit.apply` 复用已检查 gitlink 的 recorded diff，经共享转换提取目标 entry；`ManagedAutomationService.run` 将一次 findOccurrence 的 settled 行同时用于 skipped 判断与 reason；`RuntimeBrokerService.releasedSession` 复用调用链已取得的 owner binding，而非再次按相同 bindingId 查询。仍执行原 generation、Runtime state 和释放判定，不新增跨请求缓存、快照事务或放宽并发 revalidation。最新 main 已包含三处变更。

## 关键代码路径

- `packages/managed-agent-server/adapters/src/main/java/com/alibaba/qwen/code/managedagent/adapters/workspace/ChildWorktreeGit.java`：复用本次 recorded tree diff。
- `packages/managed-agent-server/control-plane/src/main/java/com/alibaba/qwen/code/managedagent/automation/ManagedAutomationService.java`：复用同一次 settled occurrence。
- `packages/managed-agent-server/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/service/RuntimeBrokerService.java`：沿 releasedSession 使用原 owner binding。

## 验证方式

本次仅核三文件 diff、合入调用链与 main，未执行测试或基准。Java 从 `packages/managed-agent-server` 执行 `mvn -Dtest=ChildWorktreeGitTest,ManagedAutomationServiceTest,RuntimeBrokerServiceTest test checkstyle:check`，需 JDK 21、匹配 SDK；检查 gitlink/冲突拒绝、skipped 原因和 binding generation/state 变化时的释放拒绝。SQL/Git 调用次数及吞吐改进需独立测量，不能从删掉查询推断收益幅度。
