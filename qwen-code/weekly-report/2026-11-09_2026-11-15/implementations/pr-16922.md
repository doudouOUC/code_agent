## 解决了什么问题

RuntimeBrokerService 同时承载续租、Session 释放、drain/原资源停止与工具执行，公共入口和内部生命周期状态难以单独审阅。

## 最终实现方案

保留 RuntimeBrokerService 公共 facade，将 BindingRenewal、RuntimeSessionRelease、RuntimeDrainCoordinator 提取为同包协作者，沿原 repository、clock、scheduler、closed 与 claim factory 组合。原 operation generation/lease、CAS、未结 execution、drain receipt 与资源身份判定继续约束释放，提取不引入新事务或跨步缓存。

RuntimeObservation.matchesRuntime 集中 handle/instance/lease/epoch/endpoint 身份比较，READY attestation 仍另验。RuntimeBrokerSupport 区分 provider protocol v3 与 deferred publication v3，避免把两种 reference 编码混为同一条件；相关 dispatch/cancel/reconcile 调用点同步，class-size pin 跟随职责移动。

## 关键代码路径

- `packages/managed-agent-server/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/service/RuntimeBrokerService.java`：公共 facade、构造和委托。
- `packages/managed-agent-server/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/service/BindingRenewal.java`：原 operation claim 续租与停止标记。
- `packages/managed-agent-server/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/service/RuntimeSessionRelease.java`：Session 释放与回执结算。
- `packages/managed-agent-server/runtime-broker/src/main/java/com/alibaba/qwen/code/runtimebroker/service/RuntimeDrainCoordinator.java`：drain、原资源关闭及恢复编排。
- `packages/managed-agent-server/contracts/src/main/java/com/alibaba/qwen/code/runtimebroker/RuntimeObservation.java`：身份比较，不代替 READY attestation。
