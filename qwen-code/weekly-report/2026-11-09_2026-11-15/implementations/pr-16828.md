# PR #16828 最终实现：降低 proof 复制与启动轮询开销

> PR: [perf(managed-agent): cheapen proof copies, CSI lookup and startup polling](https://github.com/QwenLM/qwen-code/pull/16828)
> 状态：merged；最终 head `18890bd33ba1`，merge `cb11ba12b3f8` 已在 main；对照 main `74b8cde46612`。
> 规模：+26 / -12，5 个文件

## 解决了什么问题

TerminalProof 每次复制平面 Activation 都经 JSON 往返，CSI lookup 为每个参数重新编译并从头扫描谓词正则，Kubernetes/CSI/SSH 启动等待固定 100 ms 轮询，造成无必要的 CPU/请求开销。

## 最终实现方案

Activation 按字段复制，仍对可变 installRef 做 deepCopy；其他 proof 的深复制路径不删除。CSI inventory 将 LOOKUP_FIELD 预编译，每次 lookup 使用一个 matcher 顺序消费参数字段，保留原编码和 column-kind 校验。三个 provisioner 的 startup pause 从 200 ms 起翻倍、封顶 2000 ms，原 deadline、身份观察、终态冲突与中断语义不变；不缓存 Ready、不减少实际资源身份检查。
