# PR #17064 最终实现：单一可执行分发 JAR

> PR: [refactor(managed-agent): collapse the distribution to a single executable jar](https://github.com/QwenLM/qwen-code/pull/17064)
> 状态：merged；最终 head `96e6801fd98c`，merge `6a1627e4b480` 已在 main；对照 main `7fab512f79d9`。
> 规模：+53 / -252，23 个文件

## 解决了什么问题

控制面与六种 operator classifier 重复打包，发布脚本和环境参数需要维护多份同代码产物，容易产生版本错配。

## 最终实现方案

最终实现删除六种 operator classifier 的 resources/repackage execution 及 no-operator-tools profile/属性，保普通 library JAR 和一个 exec JAR；不是承诺构建只产生一个文件。维护命令类仍在，通过现有 admin launcher 或 PropertiesLauncher 的 -Dloader.main 从 exec JAR 运行。

reference package 去掉独立 operator-recovery JAR/binary，保 server/admin/bootstrap 辅助入口。ManagedAgentPackagingIT 不再按 classifier 检查六份副本，改用 exec JAR 的 loader.main 启动恢复命令，并保 library 不携独立配置的检查。main 已只保一个 exec 分发与普通 library；#17139 后续删除旧 tag repair，但不删除维护命令。

## 关键代码路径

- `packages/managed-agent-server/server/pom.xml`：只保 exec repackage 与普通库产物。
- `packages/managed-agent-server/verification/src/test/java/com/alibaba/qwen/code/managedagent/ManagedAgentPackagingIT.java`：exec/library 与 loader.main 打包验收。
- `scripts/package-managed-agent-reference.mjs`：reference package 文件集合。

## 验证方式

本次仅核 POM、脚本、完整文件清单与测试定义，未运行打包、进程或 CI。固定最终 head 可在根目录分别执行 `node --test scripts/tests/package-managed-agent-reference.test.mjs` 和 `npm run test:scripts:unit -- scripts/tests/managed-runtime-release.test.js`。Java 需 JDK 21、Maven >=3.8.9、匹配 SDK 与隔离仓库；ManagedAgentPackagingIT 绑定 verification 模块 integration-test 阶段，必须先生成 server 产物，再按仓库 CI 的打包生命周期验证，不能用未打包的直接单测替代。
