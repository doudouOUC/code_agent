## 解决了什么问题

嵌入宿主的调度器候选隔离缺少覆盖所有实际 bean 的断言；历史 tag repair 分支和补丁继续绑住发布/验证结构，收敛提案也容易与已落地行为混淆。

## 最终实现方案

ManagedAgentEmbeddingTest 枚举上下文实际 ThreadPoolTaskScheduler，排除 Boot taskScheduler，要求 Managed bean 的 defaultCandidate=false 并包含关键池。生产 sessionWorktreeScheduler 的属性修正已在 #17058，本 PR 补回归而非再次改生产 bean。

release-managed-runtime workflow 删除 v0.26.3/v0.26.5 两个条件 repair step、三份 patch 及其专属测试；保单独的禁止跳过 Javadoc gate 断言，不改旧 tag，也不再承诺旧 tag backfill。新增双语 preproduction convergence 设计：单 Public API、模块/Settings/preflight/schema 收敛仍属提案；HTTP 合并与协议代际清理按原设想撤回，现行双服务和多代协议仍在。文档对仓外宿主的陈述本次未独立取证，不据此承诺宿主迁移完成。
