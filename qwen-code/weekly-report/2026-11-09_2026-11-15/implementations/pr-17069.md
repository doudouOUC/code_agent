# PR #17069 最终实现：legacy CSI guard 的普通 root 与 collector 读边界

> PR: [fix(managed-agent): stop the legacy CSI guard from gap-locking other Sessions](https://github.com/QwenLM/qwen-code/pull/17069)
> 状态：merged；最终 head `3ebd3e00c0fe`，merge `7fb36683550b` 已在 main；对照 main `7fab512f79d9`。
> 规模：+336 / -35，8 个文件

## 解决了什么问题

在 CSI pin 二级索引上对不存在的 pinned entry 做锁读，会留下覆盖其他 tenant 新 Session 的 gap lock；collector 若过早建立一致快照，又可能漏看等待 head 期间提交的 read lease。

## 最终实现方案

ManagedLegacySessionGuard.isPrivate 先按 tenant/Session 主键作一致读：可见且未 pin 的普通 root 直接返回 false；pinned 或快照中缺失的 root 才作主键 FOR UPDATE，并保 namedRootDeadlock 映射。移除 FORCE INDEX 与 is_csi_guard=TRUE 的二级索引锁探测。缺失 root 分支仍可能留下主键插入 gap，不能概括为消除所有 gap lock。

ManagedProjectionResourceCollector 已持 publication guard，改用 isPrivateCurrentRead，直接锁 root 后再锁 head；不在等待锁前用普通快照固定 REPEATABLE READ 视图，从而能检查等待期间提交的活 read lease。新增 MySQL 独立连接用例区分普通 root 不阻塞、pinned root 仍锁、absent root 残余 gap 和 collector 不误回收；这不是取消 CSI pin 或 read lease。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/ManagedLegacySessionGuard.java`：普通可见 root 快路径与 current-read 专用入口。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/ManagedProjectionResourceCollector.java`：保持 guard→root→head 与 lease 可见性。
