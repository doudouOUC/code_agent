## 解决了什么问题

旧 FAILED/PENDING rename 键可以重新结算出新 revision，但 replayed=true 使 !replayed 通知条件漏发；恢复测试和 OpenAPI 仍描述被删除的 delivery 路径。

## 最终实现方案

ManagedAgentService 改以 result.revision()>0 决定提交后通知：旧键重新结算仍发新 revision，真正 COMPLETED replay 的 revision=0 不重发。Harness 不支持 fenced title 时写 debug 并保 SQL 成功，不恢复异步 delivery。

修复 SessionRecoveryInitialStateTest 以同步入口建立状态；补旧失败重试、连续 revision 和纯重放无通知测试。更新 OpenAPI 1.115.0 与生成 TS 的 WebShell 描述，明确 SQL 显示权威及 journal 尽力同步，不改变响应形状。renameSupported 仍保 Harness 可用性门禁。
