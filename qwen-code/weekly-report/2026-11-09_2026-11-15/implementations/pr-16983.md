# PR #16983 最终实现：journal pack builder 租约与发布事务

> PR: [fix(managed-agent): fence concurrent journal pack publication with a builder lease](https://github.com/QwenLM/qwen-code/pull/16983)
> 状态：merged；最终 head `ab0faeaea17b`，merge `dfbaa817fce4` 已在 main；对照 main `19c6af15b730`。
> 规模：+113 / -22，10 个文件

## 解决了什么问题

多副本同时构建相同范围 pack 时，后来的 builder 可能删除仍活跃的 BUILDING 行；发布若未核行数，还可能推进 watermark 却没有可读 pack。

## 最终实现方案

JdbcJournalPacks 为副本生成 builderId，BUILDING 使用十分钟租约。ma_journal_pack 增加非空 builder_id，insertBuilding 只能回收本 builder 或 gmt_modified 已过期的 BUILDING；其他活跃 builder 的相同范围保留唯一键冲突，不抢占其行。

JournalPackTransactions 在同一事务逐步核 BUILDING→VERIFIED、head watermark CAS、VERIFIED→PUBLISHED 都恰好一行；被置换或 CAS 失败即回滚，不留下孤立 watermark/manifest/resource 引用。V1 baseline 与投影同步，无新增业务表或在线升级链。十分钟是回收边界，不是无限续租或对象 PUT 全局互斥承诺。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/JournalPackTransactions.java`：回收条件及三步发布行数围栏。
