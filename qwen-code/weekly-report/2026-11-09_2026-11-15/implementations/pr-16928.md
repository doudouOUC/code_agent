# PR #16928 最终实现：删除无生产调用的 CSI 与 Workspace catalog 代码

> PR: [refactor(managed-agent): remove uncalled CSI admission and workspace catalog code](https://github.com/QwenLM/qwen-code/pull/16928)
> 状态：merged；最终 head `813789207554`，merge `11b8a5b3614e` 已在 main；对照 main `19c6af15b730`。
> 规模：+3 / -1812，13 个文件

## 解决了什么问题

已无生产调用的独立 Workspace catalog/静态授权与 CSI READY admission 仍占据代码和测试入口，容易被误认为现行准入 authority。

## 最终实现方案

删除 WorkspaceCatalog、ResolvedWorkspace、WorkspaceAccessPolicy、ConfiguredWorkspaceRegistry、GrantedWorkspaceAccessPolicy、JdbcCsiReadyAdmission 和仅供旧路径的测试/LegacyEvents。保留现行 JdbcManagedWorkspaceRegistry、ContextBinding、原 Session admission 与实际 CSI execution 校验；构造器/文本字段测试移除已不存在的类引用。该 diff 无新存储实现、schema 或公共 wire 字段变化，不把删旧 catalog 写成取消 Workspace 授权。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/JdbcManagedWorkspaceRegistry.java`：当前仍使用的持久 Workspace 准入与查询入口。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcCsiExecutionAdmission.java`：当前实际 CSI 执行围栏。
