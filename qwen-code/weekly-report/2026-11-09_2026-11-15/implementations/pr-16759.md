# PR #16759 最终实现：区分 repository 接口与 JDBC 实现名称

> PR: [refactor(managed-agent): give JDBC stores names distinct from their interfaces](https://github.com/QwenLM/qwen-code/pull/16759)
> 状态：merged；最终 head `ddeaef56e748`，merge `abf5cb4b9261` 已在 main；对照 main `19c6af15b730`。
> 规模：+3919 / -3483，386 个文件

## 解决了什么问题

repository 接口与 persistence 实现使用同一简单类名，调用方与实现内部不得不用大量全限定名，`ManagedSessionStore` 等名称随 package/import 改变含义，增加事务入口和锁契约审阅的歧义。

## 最终实现方案

23 个执行 JDBC 的实现类改为 `Jdbc<接口名>`，如 `JdbcManagedSessionStore`、`JdbcWorkspaceExecutionStore`；调用方注入的 repository 接口保留名称。非 JDBC 的 artifact reader 改为 `ToolPublicationArtifactReader`；child worktree 端口改为 `ChildWorktreeOperations`，适配器仍名 `ChildWorktreeGit`。同步构造器、import、类型引用以及 verification 的锁签名、SQL owner 路径和 class-size pin；少量新增 import 带来的上限调整不代表放宽全局体量门禁。

该 diff 是符号/引用重构，不改 SQL、wire 字段、JSON、配置键或 schema，不改变 Session-before-Turn、writer fencing 和事务 facade。默认 Spring bean 名与按类 logger 分类会随类名变化，不能把“运行时契约不变”误写成所有可观察名字都不变。最新 main 已沿新路径继续演进，历史文档中的旧实现路径只作旧快照。
