# PR #16923 最终实现：冻结 CSI commit 按正文上限读取

> PR: [fix(managed-agent): read the frozen CSI commit body with its own size bound](https://github.com/QwenLM/qwen-code/pull/16923)
> 状态：merged；最终 head `2051166b179b`，merge `47362ace4aea` 已在 main；对照 main `19c6af15b730`。
> 规模：+59 / -95，5 个文件

## 解决了什么问题

commitBodyBase64 被短文本 helper 的 4096 字符上限截住，合法正文超过约 3072 字节即拒绝，可能使 CSI 退役停留在 FROZEN。

## 最终实现方案

JdbcCsiRetirementEvidence.frozenCommit 改用 WorkspaceCsiApplicationJson.base64，冻结 envelope 保 32 MiB，合入时 commit body 独立限 128 KiB；后续 #16956/#16981 已统一为 body 256 KiB（record 仍 128 KiB、candidate 16 KiB、command 384 KiB），继续核 canonical base64 和 preparedCommitSha256，再解析对象。不放宽原 envelope/摘要/退役身份检查。删除已失效的 inventory 相关残留，新增超过旧短文本阈值及错误编码/摘要的聚焦回归；#16934 随后让公共 proof helper 同样尊重调用方限额。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcCsiRetirementEvidence.java`：独立正文限额与摘要校验。
- `packages/managed-agent-server/contracts/src/main/java/com/alibaba/qwen/code/managedagent/contracts/persistence/WorkspaceCsiApplicationJson.java`：canonical base64 解码与长度拒绝。
