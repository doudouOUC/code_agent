## 解决了什么问题

JdbcRuntimeBrokerSchema 仅将 initialize 原样转发 ManagedSchema，造成“Broker 独立 schema”的误导和额外公共名称。

## 最终实现方案

删除十三行 JdbcRuntimeBrokerSchema alias，将八个 verification 调用方及 runtime-broker 说明直接指向 ManagedSchema.initialize。原入口仍初始化唯一 V1 或验证既有 catalog，并拒 legacy/partial/foreign/history-only 状态；本 PR 未改 DDL、catalog 校验、SQL/wire 或生产 wiring。

测试仍比较 Flyway baseline 与显式 initializer 形状、重复初始化和旧 catalog 拒绝；名称清理不是引入升级链。仓外若直接依赖旧 public alias，源码调用需改入口，不能由仓内仅测试调用推导二进制兼容。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/managedschema/ManagedSchema.java`：保留的唯一 fresh catalog 初始化/校验入口。
