## 解决了什么问题

journal pack 发布并删除 SQL 正文后，activation lease 和 CSI saved/history 仍直接读 record_bytes，可能把合法已外置记录当损坏。

## 当前实现方案

当前 open diff 增加包内 CsiPackRecords：优先 inline，否则调用共享 JdbcJournalPacks.resolveBytes；即使 inline 也核 SQL 长度/sha，缺少 pack、字节或摘要不符均返回失败，由调用者 fail closed。JournalStoreRows.activationLeaseRow 读取 byte_length 并接对象存储/pack 依赖。

activation/execution admission、retirement saved/history 与 binding/execution repository 读路径通过构造和 RuntimeBrokerConfiguration 共享 pack 解析，维护入口与 SideQueryStore 同步接线。新增 pack-only/损坏场景测试；main 仍没有该 helper，且删除资格不能仅凭候选测试定义认定通过。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/CsiPackRecords.java`：候选 inline/pack 解析和 SQL 摘要核验。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/JournalStoreRows.java`：候选 activation lease pack fallback。
- `packages/managed-agent-server/server/src/main/java/com/alibaba/qwen/code/managedagent/config/RuntimeBrokerConfiguration.java`：候选共享 pack 依赖接线。
