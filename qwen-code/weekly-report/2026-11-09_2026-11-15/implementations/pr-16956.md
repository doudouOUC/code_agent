## 解决了什么问题

terminal record 与 candidate 经 base64 嵌套进入 body/command 后会膨胀；分散的限额可能让内层合法证据在外层拒绝，导致退役流程无法完成。

## 最终实现方案

CsiNativeActivationProof 统一拥有四层预算：record 128 KiB、candidate 16 KiB、body 256 KiB、command 384 KiB。body 从 128 KiB 调至 256 KiB，command 从 192 KiB 调至 384 KiB，容纳内层 base64 膨胀；JournalCommit、CSI application/history、activation 与 retirement 读取复用常量。

边界检查仍要求 textual、非空、长度合规及 canonical base64，原 digest/身份和退役 seal 不放宽。#16981 随后补齐 terminalHistory 的剩余 body 读取检查；正文上限不能与 record 上限混称。
