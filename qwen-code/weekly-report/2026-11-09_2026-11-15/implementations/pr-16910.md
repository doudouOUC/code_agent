# PR #16910 最终实现：CSI 退役只读取原 Session 证据

> PR: [refactor(managed-agent): scope CSI retirement evidence to its own session](https://github.com/QwenLM/qwen-code/pull/16910)
> 状态：merged；最终 head `424f94b7cdac`，merge `c6fac1a831de` 已在 main；对照 main `7fab512f79d9`。
> 规模：+348 / -7598，26 个文件

## 解决了什么问题

退役应用通过全库 inventory/image 构造证据，扩大扫描、锁与跨 tenant 审阅范围；原 Session 的退役不应依赖无关 Session 的应用表快照。

## 最终实现方案

新增 JdbcCsiRetirementEvidence，从原 binding/Session 范围获得 terminal proof、execution、resource resolver 和 sealed binding version；saved 与 historical 路径重复核退役 seal、原 journal 和 Worker 回执。历史读取沿只读 REPEATABLE READ、有界时间与原 credential 验证。

WorkspaceCsiApplicationStore/History/WorkerMatch 改消费上述 evidence；删除 WorkspaceCsiApplicationInventory、Image/Identities 和 CSI 专用诊断投影及对应全库测试，JournalCommit 的普通诊断投影保留。不是取消 CSI 原 owner/lease/receipt 围栏，也不是全库应用镜像可迁移的证明；同周 #16923/#16934 进一步修正证据正文读取上限。

## 关键代码路径

- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/runtimebroker/persistence/JdbcCsiRetirementEvidence.java`：Session 范围 live/saved/historical 证据。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/WorkspaceCsiApplicationHistory.java`：只读一致快照下复核原退役应用。
- `packages/managed-agent-server/persistence/src/main/java/com/alibaba/qwen/code/managedagent/persistence/WorkspaceCsiApplicationStore.java`：受理与读取消费原范围证据。
