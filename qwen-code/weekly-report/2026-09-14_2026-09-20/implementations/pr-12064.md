# PR #12064 当前实现观察：把 bwrap 约束迁移到工具执行

> PR: [feat(core): Move bwrap confinement to tool execution](https://github.com/QwenLM/qwen-code/pull/12064)
> 状态：open draft；以下仅按 2026-09-21 快照 head `7db66d527166` 描述当前总体方案，不能作为 `main` 已落地能力。
> 规模：+8800 / -3141，132 个文件

## 解决了什么问题

#11614 的 whole-CLI bwrap 会把模型通信、认证、审批和 session state 一并放入命令网络/文件系统边界，扩大工具所需权限对可信宿主逻辑的影响。反过来若只包装 Shell，Write/Edit、prompt shell、Monitor 与其它直接副作用仍可绕过。目标是把 kernel confinement 收敛到每个工具副作用，同时让宿主控制面保持正常运行。

## 当前实现方案

当前 draft 定义 operator-only、runtime immutable 的 `tools.executionSandbox`，要求显式 filesystem `read-only|workspace-write` 与 command network `open|closed`，backend 仅 `auto|bwrap`。User/System 设置可决定策略，Workspace/project dotenv/bare/safe/嵌套 agent 不能删除或放宽。旧 `tools.sandbox:bwrap`、环境变量和 CLI selector 返回迁移错误；bwrap 不可用、设置损坏或 unsupported integration 必须在副作用前 fail closed，不能回退无约束执行。

执行层把 Shell、Ink/OpenTUI `!`、prompt interpolation、Monitor、Read/Write/Edit 和受支持的同 workspace Agent/Code Mode 接到结构化 bwrap adapter/文件 worker。CLI 的模型 transport、auth、approval 和 session persistence 留在 host。draft 同时删除 whole-CLI bwrap 路径，更新 `qwen sandbox` 为工具边界的 inspect/verify/command 入口，并对 ACP/serve/web terminal、hooks/MCP/LSP、技能准备、Omni 等未适配路径显式禁用或拒绝。

该 PR 还包含 x64/ARM64 无凭据 acceptance workflow，报告 62 项 public CLI、31 项 runtime 与 34 项 adapter 验证，并保留 hash/fixture 证据。但当前 132 文件总体实现仍是拆分参考；#12067 只抽取内部 execution foundation，#12269/#12267 分别承接 runtime integration 与公开 cutover，尚未形成 `main` 公开能力。

## 关键代码路径

- `packages/core/src/config/config.ts` 与 CLI settings/safety paths：operator policy 解析、来源优先级、immutability 和 migration refusal。
- `packages/core/src/sandbox/`、`services/shellExecutionService.ts`：结构化 launch、bwrap relay/receipt、文件 worker 与 tool execution wiring。
- `packages/core/src/tools/`：Shell/Read/Write/Edit 等 effect boundary 接入。
- `packages/cli/src/ui/`、`commands/sandbox.ts`：Ink/OpenTUI shell、policy 展示和 inspect/verify UX。
- `.github/workflows/sandbox-bwrap.yml`、`scripts/sandbox-public/`：x64/ARM64 public/runtime/adapter acceptance。

## 边界与风险

- 仍允许广泛 host read 与 pathname Unix socket，不承诺 secret confidentiality 或完整宿主隔离。
- Landlock、权限扩展、代理 command network、ACP/serve/web terminal 与多种 extension path 不在当前交付范围。
- 该 draft 删除旧 backend 并引入配置迁移，只有完整切片全部合入后才能形成可用公开能力。
