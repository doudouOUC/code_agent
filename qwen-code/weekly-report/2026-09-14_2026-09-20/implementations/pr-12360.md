## 解决了什么问题

内置主会话 prompt 重复项目约定、语气、工具使用和交互规则，并在 headless 无法接收回复的模式中保留会主动追问的示例。重复文本增加基础上下文，冲突示例又可能覆盖明确的 no-reply 规则；五种 prompt format 各自维护七套示例也扩大漂移面。

## 当前实现方案

该 PR 合并重叠规范，并把 general、qwen-coder、qwen-vl、gemma4 与 CodeModeOnly 五种示例集各从七个工作流压缩为三个：受管理后台 server、范围明确的重构、先读取目标再新增测试。保留示例继续要求先读源码、完成验证后才报告结果，并删除会在 headless 模式主动问用户的回复。

prompt assembly 仍根据实际 tool availability 过滤不兼容示例，没有剩余示例时省略 heading。interactive/ACP 澄清指导、headless no-reply、CodeModeOnly 的 exec/并行/输出/依赖顺序、输出风格、自定义 override、模型路由、权限/sandbox/Git 安全段均保持原边界。当前 head 是实现提交 `318f28c2df77` 合并最新 `main` 后的 merge commit。
