## 解决了什么问题

冷启动时仅根据路径重新挂载，不能证明它仍是原 storage，也可能读取不一致的 journal/resource。

## 最终实现方案

Linux opt-in storage guard 以注册记录、marker 和文件身份验证原挂载；Hosted load 校验 Session 定义、journal/checkpoint 与 durable resources，核对原 Shell receipt，再允许已证明边界恢复。

## 关键代码路径

- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/WorkspaceStorageGuard.java`：原 storage 注册和身份核验。
- `packages/cli/src/serve/hosted-harness-session.ts`：cold load 资源与 receipt 校验。
