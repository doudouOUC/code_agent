## 解决了什么问题

daemon Session 的审批模式可在运行时由 ACP 或控制扩展改变，但冷加载仅看 workspace settings，导致 Plan/Full Access 等会话级决策在重启后丢失或被未变化的 settings 覆盖。

## 最终实现方案

合入代码将 `session_approval_mode` 作为 Session transcript 的 system record 写入，包含 mode、Plan 前置 mode 和可选执行模式；transcript projection 读取最新记录。冷恢复时 `applyRestoredSessionApprovalMode` 对非受限会话应用该记录，Plan 先恢复其前置 mode 再进入 Plan；bare/safe 仍不能被记录提升权限。daemon 将 settings 文件派生的收敛值与会话当前值分开跟踪，未变化的文件重载不覆盖会话内切换；实际 settings 改动仍按原策略收敛。录制失败告警，不静默宣称持久化成功。
