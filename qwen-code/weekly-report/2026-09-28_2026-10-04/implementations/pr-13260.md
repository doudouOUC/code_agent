## 解决了什么问题

原 storage 无法直接替换为新挂载；迁移若与 live writer 并发，可能破坏原 journal 和 Session 身份。

## 最终实现方案

离线 migration operation 固定 request digest 和 storage fence；retire 原资源后用 W1b bundle 验证历史与目标 marker，分阶段准备/完成存储注册迁移。公共 Session 和 journal 事实保持原身份。

## 关键代码路径

- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/WorkspaceMigrationStore.java`：迁移状态、storage fence 和幂等。
- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/WorkspaceStorageGuard.java`：目标注册与历史验证。
