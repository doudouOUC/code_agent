## 解决了什么问题

普通本地 `qwen serve` 的 Managed engine 曾与 Hosted 首个交付闭环并列推进，容易把本地 M2/M4–M6 误列为 Hosted 前置条件，模糊已有 M1/M3 与尚未实施的部分。

## 当前实现方案

当前 diff 更新中英文双引擎宿主与普通本地 Managed engine 设计：保留已合入的 M1 owner 保护和 M3 兼容评估，把 M2 子进程宿主、M4 Session log、M5 会话独占 Runtime worker、M6 注册/启用排到 Hosted 工具执行、持久结果与故障门禁验收之后。未来本地方案改为每 Workspace runtime 按需 Managed 子进程，首版会话独占 worker；这仍是目标设计，不是本 PR 的产品代码。
