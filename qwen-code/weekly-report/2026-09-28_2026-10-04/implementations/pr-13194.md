## 解决了什么问题

close 成功后的绑定 Session 无法安全 archive/delete，unarchive 也可能错误重新开放执行。

## 最终实现方案

要求持久 close receipt 和 creator 权限后才准入 retention operation；archive/delete 复用生命周期状态，unarchive 将记录恢复为 CLOSED，原幂等 key 重放身份。

- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/store/ManagedAgentStore.java`：close receipt、creator 与 retention 状态。
- `packages/sdk-java/managed-agent-server/src/main/java/com/alibaba/qwen/code/managedagent/service/ManagedAgentService.java`：公共/WebShell capability。
