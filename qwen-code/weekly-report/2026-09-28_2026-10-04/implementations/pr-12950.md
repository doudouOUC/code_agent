## 解决了什么问题

Hosted 模型一次提交多个文件工具调用时，非法绝对路径或 `..` 路径若只在内存里抛错，模型看不到可纠正的有序回执；若同批有效调用先执行，还可能产生部分副作用。

## 当前实现方案

当前 diff 在 dispatch 前逐个规范化 `file_path`；缺失、绝对路径或穿越触发整批拒绝。`HostedWorkspaceToolTurn` 先提交 assistant 调用，再把每个 call 的 `tool_result` 错误按原顺序写入 Session authority：非法项说明如何修正，其他项说明本批未执行；没有 Broker acquire/prepare/execute。两次提交间失败标记 `uncertain` 并要求恢复，不把部分持久记录当成功回执。集成驱动覆盖模型同轮纠错。

## 关键代码路径

- `packages/cli/src/serve/hosted-workspace-tool-turn.ts`：路径校验、整批拒绝与双记录提交。
- `packages/cli/src/serve/managed-workspace-binding.ts`：相对路径规范化和穿越拒绝。
- `packages/cli/src/serve/hosted-workspace-tool-turn.test.ts`：有序持久回执与无副作用测试。
- `packages/sdk-java/managed-agent-server/src/test/java/com/alibaba/qwen/code/managedagent/HostedWorkspaceToolTurnIT.java`：跨端场景入口。
