## 解决了什么问题

#7761 合入后，review 继续指出 benchmark 有几个会影响解释力的问题：dwell anchor 绑在 session readiness 会把 SSE 未就绪时间混进 provider idle window；benchmark runner 跟普通 integration tests 共用 config，可能被并行调度污染；Phase 1 gate 只看裸 percentile diff，不足以表达 paired comparison 的不确定性；artifact schema 中 bundle-level git commit 会把两个变体都错误标成当前 checkout head。

## 当前实现方案

当前 diff 把 dwell anchor 改为 SSE readiness，并把 actual idle window 写入 artifact。benchmark runner 从共享 integration config 中拆出专用 serial config，避免与其它 integration tests 并发运行；helper tests 仍留在共享 config，保持快速反馈。

paired comparison gate 改用 paired bootstrap CI lower bound，只有置信区间下界满足阈值才判定通过；percentile diff 继续记录，作为历史连续观察字段，而不是唯一 gating 信号。duration 归一化覆盖所有 invalid duration，success predicate 合并成单一来源，减少 artifact 与统计逻辑漂移。

schema 方面删除 bundle-level git commit，重命名原本只是 prompt shape 说明文字的字段，并提升 schema version。comparison-only dwell parsing 移到 single-mode reject 之后，这样配置错用时先返回准确模式错误，再解释 dwell 参数。设计文档同步修正 buffer overflow、cold/warm delta、median 定义和 compile-cache dir 记录/teardown 语义。
