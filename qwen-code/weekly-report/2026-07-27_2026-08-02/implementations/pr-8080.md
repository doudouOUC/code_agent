## 解决了什么问题

workspace skills/status 是 dashboard、IDE 和 Web Shell 会频繁轮询的只读状态面，但旧实现会在每次读取时重新做 extension discovery、workspace settings load 和完整 skill cache refresh。一个受影响会话会产生 232,406 条 `SKILL_LOAD` 日志，并把 11 个 extension skill 目录重复扫描 2,554 次。读状态本身变成了昂贵 mutation，既浪费 CPU/IO，也会让 extension-derived skills 在并发 mutation 时反复抖动。

## 最终实现方案

最终实现把 workspace skill status 拆成 side-effect-free read model 与显式 refresh mutation。ACP child 的 `workspaceSkills` status 只读取已提交的 `SkillManager.getCachedSkills()` snapshot；如果缓存尚未初始化，返回 `initialized:false`，让 daemon fallback 到本地枚举，而不是在只读请求中触发 refresh。

daemon 侧对 workspace skills status 增加 5 秒 TTL、generation guard 和 single-flight。mutation 前后都会 invalidate generation；只有与当前 generation 一致的读结果才能更新 `lastWorkspaceSkillsStatus`，避免旧读在 mutation 后把 stale snapshot 重新塞回缓存。HTTP route 增加 `ETag` / `If-None-Match`，并通过 CORS expose header 让 SDK/浏览器客户端可以做条件 revalidate。

settings、skill content 和 extension mutation 改走带 reason 的显式 refresh。`workspaceSkillsRefresh` 支持 `settings` / `content` / `all`，settings-only 路径不刷新 skill content，content path 刷新所有相关 `SkillManager`。extension source 没有 watcher，所以只在 read path 做轻量 fingerprint revalidation：`ExtensionManager.refreshCacheIfSourcesChanged()` 用 extension manifest、enablement file 和 state file 的 mtime/size 判断是否真的需要 refresh，稳态读不解析 manifest 和 `SKILL.md`。

ACP bridge 还 coalesce overlapping extension refresh。每个 session 共享 in-flight refresh；每个 ACP connection 只做一次 bootstrap refresh，若负责 bootstrap refresh 的 session 消失，会尝试用同 connection 上已成功的 session 重试。workspace extension mutations 在刷新前后都 invalidate workspace skill snapshot，避免 racing read 重新延长 stale TTL。

## 关键代码路径

- `packages/core/src/skills/skill-manager.ts`: 新增 `getCachedSkills()`，把 read-only status 与 `listSkills()` 的 refresh 行为分离。
- `packages/core/src/extension/extensionManager.ts`: 新增 source fingerprint 与 `refreshCacheIfSourcesChanged()`，让 extension-derived skills 稳态读取不反复扫描。
- `packages/cli/src/acp-integration/acpAgent.ts`: `workspaceSkills` 改读缓存；`workspaceSkillsRefresh` 按 reason 刷 settings/content；extension refresh 补 bootstrap coalescing。
- `packages/cli/src/serve/workspace-service/index.ts`: workspace skill snapshot TTL、generation guard、single-flight、mutation invalidation。
- `packages/cli/src/serve/routes/workspace-extensions*.ts`: extension mutation 前后 invalidation 与 refresh result 处理。
- `docs/design/workspace-skills-read-model.md`: read model、cache invalidation 与 mutation/refresh 边界。
