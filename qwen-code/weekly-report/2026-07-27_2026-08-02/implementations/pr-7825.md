## 解决了什么问题

#7761 的 first-output benchmark artifact 中有几个 review follow-up 需要单独修正：bundle-level git commit 字段会把所有变体错误标成当前 checkout head；prompt shape 字段名像结构化 schema，实际却是说明文字；ordering balance check 在当前 AB/BA 生成逻辑下不可达；success predicate 重复实现容易让 artifact 与 gate 口径分叉。

## 最终实现方案

最终实现删除 bundle-level git commit 字段，把 prompt shape 字段重命名为更明确的说明字段，并提升 artifact schema version。这样 artifact 不再声明无法证明的 bundle provenance，也避免 consumer 把说明文字当成结构化 prompt shape。

benchmark helper 同时做简化：移除不可能触发的 ordering balance check，合并重复 success predicate，comparison-only dwell 参数在 single-mode rejection 之后解析，保证配置错误能得到更准确的优先错误。设计文档也同步修正四个解释口径：buffer overflow 会同时 latch failure 和 drop frame；cold/warm delta 是 provider preload recoverability upper bound，不是 provider loading cost；artifact 中两个 median 定义并存；compile-cache dir 会被记录到样本中，但 teardown 会删除实际目录。
